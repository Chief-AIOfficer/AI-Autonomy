# deep-research: исследования в Claude Code с проверкой каждого факта

Скилл для [Claude Code](https://code.claude.com), который превращает вопрос в отчёт с источниками, где каждое несущее утверждение открыто в первоисточнике отдельным проверяющим, а то, что найти не удалось, так и названо.

Что получаете на выходе:

- `report.md` и `report.html` (в HTML резюме выделено, ссылки на источники кликабельны, есть оглавление, тёмная тема);
- папку исследования с брифом, находками сборщиков с дословными цитатами и результатами проверки, чтобы любую строчку отчёта можно было отследить до источника.

## Чем он отличается от «просто спросить модель»

- **Сначала «зачем», потом поиск.** Скилл проверяет запрос по четырём осям: какое решение он питает, границы, в каком виде нужен ответ, не подогнан ли вопрос под желаемый ответ. Всё это вместе с допущениями замораживается в брифе до поиска, и отчёт не уплывает в сторону.
- **Сбор идёт параллельно.** Несколько агентов ищут каждый свой участок и пишут находки на диск по ходу работы.
- **Проверка независимая и обязательная.** Утверждения дробятся на атомарные и уходят проверяющим, которые не видят черновик. Проверяющий ищет не только «подтверждается ли», но и оговорку рядом, которая меняет смысл, и путаницу «рекомендует» с «обязывает».
- **Честное «не найдено».** Если данных нет, отчёт пишет «не найдено этим поиском» и перечисляет запросы, а не выдумывает.
- **Длина по делу.** У режимов потолки длины, а не нормы: короткий обоснованный отчёт лучше длинного.

## Установка

Нужны Claude Code и Python 3.9 или новее (только стандартная библиотека, ничего доставлять не надо).

Через маркетплейс (рекомендуется, обновления приходят штатно):

```
/plugin marketplace add Chief-AIOfficer/AI-Autonomy
/plugin install deep-research@ai-autonomy
```

Обновление: в терминале `claude plugin marketplace update ai-autonomy`, затем `claude plugin update deep-research@ai-autonomy` и перезапустить Claude Code. Первая команда только обновляет каталог, вторая ставит новую версию скилла.

Вручную, как личный скилл без плагина (ставьте одним способом из двух, иначе скилл окажется в списке дважды):

```bash
git clone https://github.com/Chief-AIOfficer/AI-Autonomy.git ~/AI-Autonomy
ln -s ~/AI-Autonomy/plugins/deep-research/skills/deep-research ~/.claude/skills/deep-research
```

Обновление: `cd ~/AI-Autonomy && git pull`. Проверка, что всё на месте: `cd ~/.claude/skills/deep-research && python3 -m unittest discover -s tests`.

## Использование

Просто попросите в Claude Code:

- «Сделай deep research: какие требования к ИИ в банках действуют в России на сегодня»
- «Исследуй в режиме deep: стоит ли переходить с X на Y для нашей задачи»
- «Быстро разберись (quick): что такое …»

Чтобы вызвать скилл явно: `/deep-research:deep-research ваш вопрос` (если ставили через маркетплейс) или `/deep-research ваш вопрос` (если вручную).

Режимы:

| Режим | Когда | Потолок длины |
|---|---|---|
| quick | сориентироваться, один узкий вопрос | 2 500 слов |
| standard | большинство вопросов (по умолчанию) | 6 000 |
| deep | решение, где на кону деньги, право или репутация | 10 000 |
| ultradeep | большой обзор, на который будут опираться месяцами | 15 000 |

В deep и ultradeep добавляются проверка каждого раздела на опору в источниках и критика отчёта свежим агентом. На старте таких прогонов бывает две короткие остановки, обе в первые минуты:

1. **Зачем.** Если в запросе не сказано, что вы сделаете с ответом, не заданы границы или вид ответа, либо вопрос просит подтвердить готовый вывод, скилл одним сообщением задаст до трёх вопросов. В том же сообщении он назовёт допущения, с которыми пойдёт, если ответить «запускай». Если всё это уже есть в запросе, вопросов не будет.
2. **Как.** Скилл покажет план (подвопросы, сборщики, примерное время) и спросит, запускать сборщиков разом или частями.

В фоновом прогоне вопросов нет: скилл додумывает решение сам и пишет об этом в первой строке отчёта.

## Куда сохраняется

По умолчанию `~/Documents/Research/<Тема>_<ГГГГММДД>/`. Другую папку можно задать переменной окружения:

```bash
export DEEP_RESEARCH_DIR="$HOME/Documents/Мои исследования"
```

Если в вашем `CLAUDE.md` написано, куда класть исследования, скилл послушается его.

## Поиск: работает на встроенном, лучше с MCP

Без настроек скилл ищет встроенными `WebSearch` и `WebFetch`. Этого хватает для большинства тем. MCP-серверы расширяют возможности, скилл сам определяет, что установлено, и выбирает бесплатное раньше платного:

| Что даёт | Примеры серверов |
|---|---|
| Выдача поисковика с операторами `site:`, Яндекс | Bright Data |
| Сырой текст страницы, обход защиты от ботов | Bright Data, Firecrawl, Tavily, Jina Reader |
| Семантический поиск | Exa, Bright Data |
| Обход сайта целиком | Apify, Firecrawl |
| Reddit (встроенные инструменты туда не пускают) | Bright Data, Apify |
| Научные статьи | серверы arXiv и Semantic Scholar |

Платные поисковые API скилл вызывает в самом дешёвом режиме и не запускает их встроенные «исследования» без вашей просьбы.

### Российские сайты

Встроенный `WebFetch` и MCP-серверы ходят за страницами со своих зарубежных серверов. Многие российские сайты такие запросы отбивают: госсайты, ЦБ, Кодекс, банки. Сертификату Минцифры, на котором работают банки, эти инструменты тоже не доверяют. Поэтому в лестнице есть ещё две ступени, и обе работают с вашего компьютера:

1. **`scripts/fetch_raw.py`** забирает текст страницы из вашей сети. Запросы к одному сайту он разносит на 4–12 секунд, чтобы не выглядеть как краулер. Корневой сертификат Минцифры лежит в `certs/`, скрипт сверяет его отпечаток и подключает только тогда, когда обычная проверка сертификата не прошла.
2. **Ваш Chrome** через расширение Claude in Chrome, если оно установлено. Годится для страниц с проверкой «вы не робот» и для платных изданий, на которые у вас есть подписка. Страницы открываются по одной, с паузами. Пароли скилл не вводит: если нужен вход, он попросит залогиниться вас.

Если у вас VPN, пускайте российские сайты мимо него (раздельное туннелирование). Иначе сайты, которые не пускают зарубежные IP, не откроются и с вашего компьютера.

## Если что-то не работает

- **`check_links.py` пишет `unchecked … TLS certificate`** почти про все ссылки. Это не битые ссылки, а Python без корневых сертификатов (так бывает с установщиком с python.org на macOS). Запустите `Install Certificates.command` из папки Python в «Программах».
- **Скилл не находится.** После установки или обновления перезапустите Claude Code. Проверить, что плагин стоит: `claude plugin list`.
- **Отчёт короче, чем ждали.** Длина в режимах это потолок, а не норма. Нужна глубина: попросите режим deep.

## Как устроен

| Файл | Что внутри |
|---|---|
| `SKILL.md` | режимы, фазы, обязательные правила |
| `reference/method.md` | инструменты, бриф, план, сбор, правила остановки поиска, перекрёстная проверка |
| `reference/verification.md` | независимая проверка: промпты проверяющих, проверка разделов, проверка выводов |
| `reference/report.md` | структура отчёта, длина, критика, выдача Markdown и HTML |
| `scripts/` | папка прогона, проверка отчёта, проверка ссылок, Markdown в HTML |
| `templates/report.html` | оформление HTML-отчёта |
| `evals/` | набор проверок самого скилла |

Инструкции для модели написаны по-английски: модели чуть надёжнее им следуют. Отчёты пишутся на языке вопроса.

## Набор проверок

В `evals/` лежат кейсы, взятые из реальных ошибок исследований (устаревшее право, неверная посылка вопроса, цифра с графика, выданная за цитату, пропущенная оговорка), 10 кейсов для проверяющего и три оценщика: опора на источник, покрытие, качество источников. Как гонять, описано в `evals/README.md`. Главное правило: прогоны сильно шумят, поэтому вывод «правка помогла» делайте по двум и более прогонам на кейс.
