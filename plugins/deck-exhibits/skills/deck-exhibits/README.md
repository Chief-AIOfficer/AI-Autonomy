# deck-exhibits

Скилл для Claude Code и Codex: выбирает приём подачи под сообщение слайда (31 приём: мост, рейтинг, динамика, структура, матрица 2×2, дерево метрики, этапы, Гант, столпы, резюме и другие), рисует его в SVG в одном стиле и собирает слайды в HTML-деку с надстрочными сносками, строкой источников, номерами и PDF.

## Что нужно

- Python 3.11 или новее. Сторонних пакетов нет.
- Chrome, Chromium или Edge для PDF, кадров PNG и проверки краёв. Путь можно задать переменной окружения `CHROME`. Без браузера HTML деки всё равно собирается.

## Как пользоваться

Скажите агенту «сверстай слайды по сторилайну», «нарисуй дерево метрики», «какой график сюда». Скилл:

1. по заголовку-выводу слайда выбирает приём (`INDEX.md`) и записывает строку «Экспонат: …, почему: …»;
2. собирает вызов по карточке приёма (`cards/`);
3. рисует, проверяет предупреждения и собирает деку рамкой `frame/deck.py` одной командой;
4. показывает кадры и отчёт проверки краёв (`align/check.py`).

Образец деки: `python3 <папка скилла>/frame/example.py` создаст `пример_деки/` с HTML, PDF и кадрами в текущей папке.

## Личный профиль

Свою тему, шрифт компании, правила и соседние скиллы можно записать в профиль, не меняя скилл. Шаблон и пути: `reference/profile-template.md`.
