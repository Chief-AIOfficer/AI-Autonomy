# Пункты с иконками (`points`)

> Собрано `build_docs.py` из `catalog.py` и кода функции. Руками не править.

**Что говорит слайд.** Несколько выводов, действий или причин, каждый с иконкой и жирным ключом.

**Брать, когда в ТЗ:** «ключевые выводы», «что делают лидеры», «пять ошибок», «результаты исследования», «шаги».

**Не брать, если:** пункты с цифрами эффекта (pillars); пунктов больше 8.

**Данные на вход:** items [{icon, text с **ключом**, title?}]; side: колонка цифр; task: фраза-задача.

**Потолки:** пунктов 2–8; текст пункта до 3 строк в колонке.

**Типы сообщения:** Главная мысль, Рекомендации, Резюме, Риски.

## Правила оформления

- Стили: plain, rule (разделители), card (серые карточки), plate (название в плашке).
- Жирное только на ключевых словах, по ним читают по диагонали.
- Иконки Lucide по смыслу, одного стиля; без эмодзи.

## Вызов

```python
import sys; sys.path.insert(0, SKILL_DIR)   # SKILL_DIR: папка скилла, см. SKILL.md
import exhibits as X
ex = X.points(items, *, cols=3, icon_pos='top', style='plain', side=None, task=None, max_lines=6, theme=None, mode='показ', width=None)
ex.svg        # строка SVG, ширина 1168 px при 1:1 со слайдом 1280×720
ex.warnings   # наложения, выход за край, мелкий кегль: пусто = чисто
```

## Параметры (из кода)

```
Пункты с иконками: ключевые выводы, что делают лидеры, результаты исследования.

items: [{'icon': 'trending-up', 'text': '**Растём** при сохранении маржи', 'title'?: 'Заголовок'}] 2–8 штук.
cols: колонок; icon_pos: 'top' (иконка над текстом) или 'left' (слева, для 1–2 колонок).
style: 'plain' (без рамок), 'rule' (тонкие вертикальные разделители), 'card' (серые карточки с полоской акцента снизу),
       'plate' (название в акцентной плашке, пояснение в серой карточке; нужен title).
side: [('~30 млрд', 'рост устройств'), ...] тёмная колонка цифр справа (до 4).
task: фраза-задача над пунктами в овале.
```

  смотреть: https://iacpm.org/wp-content/uploads/2025/03/IACPM-McKinsey-Gen-AI-Webinar-2025.pdf
- `C_recommend_02` BCG 2026: Четыре шага карточками с иконками. Вверху одна фраза-задача в овале, под ней четыре серые карточки с круглой иконкой и одним предложением. Внизу карточки зелёная полоска как «подпись». Ровно четыре пункта.
