# Карта рисков со списком (`risk_map`)

> Собрано `build_docs.py` из `catalog.py` и кода функции. Руками не править.

**Что говорит слайд.** Риски списком с номерами и на карте «вероятность × влияние»; цвет означает управляемость.

**Брать, когда в ТЗ:** «риски проекта», «что может пойти не так», «вероятность и влияние».

**Не брать, если:** рисков больше 9 (таблица в приложении); нужны меры по каждому (framework).

**Данные на вход:** risks [{name, desc, x, y, cls}], classes {cls: (подпись, роль цвета)}.

**Потолки:** рисков 2–9.

**Типы сообщения:** Риски.

## Правила оформления

- Цвет несёт один смысл (управляемость), номера одинаковые в списке и на карте.

## Вызов

```python
import sys; sys.path.insert(0, SKILL_DIR)   # SKILL_DIR: папка скилла, см. SKILL.md
import exhibits as X
ex = X.risk_map(risks, classes, *, x_label='Влияние', y_label='Вероятность', theme=None, mode='показ', width=None)
ex.svg        # строка SVG, ширина 1168 px при 1:1 со слайдом 1280×720
ex.warnings   # наложения, выход за край, мелкий кегль: пусто = чисто
```

## Параметры (из кода)

```
Список рисков слева с номерами и карта «вероятность × влияние» справа; цвет означает управляемость.

risks: [{'name': 'Каннибализация', 'desc': 'Перетекание продаж в цифровой канал', 'x': 0.8, 'y': 0.85, 'cls': 'manage'}]
classes: {'avoid': ('Можно избежать', 'accent_light'), 'manage': ('Можно снизить', 'accent_dark'), 'out': ('Вне контроля', 'accent')}
```

## Пример

`risk_map` (кадр: `python3 tests/demo.py risk_map`)

```python
def risk_map():
    cls = {'avoid': ('Можно избежать', 'accent_light'), 'manage': ('Можно снизить', 'accent_dark'), 'out': ('Вне контроля', 'accent')}
    rs = [{'name': 'Каннибализация', 'desc': 'Продажи перетекут из отделений в цифровой канал', 'x': 0.75, 'y': 0.85, 'cls': 'manage'},
          {'name': 'Ценовое давление', 'desc': 'Клиенты сравнят цены онлайн и у консультантов', 'x': 0.72, 'y': 0.7, 'cls': 'manage'},
          {'name': 'Новые игроки', 'desc': 'Конкуренты выпустят похожий продукт раньше', 'x': 0.45, 'y': 0.88, 'cls': 'out'},
          {'name': 'Низкая готовность клиентов', 'desc': 'Конверсия в цифровом канале ниже плана', 'x': 0.42, 'y': 0.45, 'cls': 'out'},
          {'name': 'Мошенничество', 'desc': 'Самообслуживание без проверки человеком', 'x': 0.3, 'y': 0.3, 'cls': 'manage'},
          {'name': 'Репутация бренда', 'desc': 'Неудача ударит по другим продуктам группы', 'x': 0.9, 'y': 0.15, 'cls': 'avoid'}]
    return X.risk_map(rs, cls)
```
