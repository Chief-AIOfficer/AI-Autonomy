# Вложенные круги рынка (`nested_market`)

> Собрано `build_docs.py` из `catalog.py` и кода функции. Руками не править.

**Что говорит слайд.** От всего рынка к доступной нам доле (TAM, SAM, SOM).

**Брать, когда в ТЗ:** «объём рынка», «доступный рынок», «наш сегмент», питч, инвесторская дека.

**Не брать, если:** уровней больше 4; части не вложены друг в друга (share_bar).

**Данные на вход:** [(уровень, значение)] от большего к меньшему; side: цифры роста справа.

**Потолки:** уровней 2–4.

**Типы сообщения:** Структура целого.

## Правила оформления

- Площадь круга пропорциональна значению.

## Вызов

```python
import sys; sys.path.insert(0, SKILL_DIR)   # SKILL_DIR: папка скилла, см. SKILL.md
import exhibits as X
ex = X.nested_market(levels, *, unit='', side=None, theme=None, mode='показ', width=None)
ex.svg        # строка SVG, ширина 1168 px при 1:1 со слайдом 1280×720
ex.warnings   # наложения, выход за край, мелкий кегль: пусто = чисто
```

## Параметры (из кода)

```
Вложенные круги рынка (TAM, SAM, SOM): от всего рынка к доступной нам доле.

levels: [('Весь рынок ИТ', 19), ('Внутренние ИТ', 5.7), ('Наш сегмент', 2.0)] от большего к меньшему; площадь ∝ значению.
side: [('40%', 'рост рынка за 5 лет'), ...] цифры справа (до четырёх).
```

## Пример

`nested_market` (кадр: `python3 tests/demo.py nested_market`)

```python
def nested_market():
    return X.nested_market([('Все расходы на ИТ в отрасли', 19), ('Внутренние ИТ', 5.7), ('ПО и услуги для управляющих', 2.0)],
                           unit='млрд $', side=[('40%', 'рост активов под управлением за 2015–2020'), ('8%', 'рост альтернатив в год, прогноз')])
```
