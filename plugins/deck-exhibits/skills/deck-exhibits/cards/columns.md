# Столбцы (`columns`)

> Собрано `build_docs.py` из `catalog.py` и кода функции. Руками не править.

**Что говорит слайд.** Ряд по периодам или сравнение категорий; выделенные столбцы и вывод рядом с графиком.

**Брать, когда в ТЗ:** «по годам» (ряд до 12 точек), «худшие годы», объекты в двух-трёх лагерях с выводом по каждому, «рост сегмента», два периода по 2–6 категориям (pair_deltas).

**Не брать, если:** больше 12 точек ряда и важна форма (lines); части целого (stacked_*); длинные подписи категорий (bar_ranked).

**Данные на вход:** категории + {серия: значения}, 1–4 серии; до 40 столбцов.

**Потолки:** серий до 4; групп с плашками 2–3; выноска одна.

**Типы сообщения:** Динамика, Сравнение и рейтинг, Разница и мост.

## Правила оформления

- Один акцент: highlight на те столбцы или серию, о которых заголовок.
- Группы с плашками-выводами (groups), если категории делятся на два лагеря.
- Рамка пунктиром (frame) вокруг худших или лучших периодов с выноской под осью.
- Врезка «И что из этого» (side) занимает треть ширины, когда вывод не помещается в заголовок.
- Две серии «было-стало» по категориям: pair_deltas, плашка разницы над каждой парой.

## Вызов

```python
import sys; sys.path.insert(0, SKILL_DIR)   # SKILL_DIR: папка скилла, см. SKILL.md
import exhibits as X

```

## Параметры (из кода)

```
Вертикальные столбцы: ряд по периодам или сравнение категорий, одна или несколько серий.

categories: подписи по оси X (годы, страны).
series: {имя: [значения]}; одна серия без легенды, несколько: подпись серии у последней группы.
highlight: имя серии, индекс категории или список индексов: что красить акцентом, остальное серое.
           Без highlight одна серия рисуется accent_dark, несколько серий цветами theme.series.
groups: [{'from': i, 'to': j, 'title': 'вывод группы', 'tone': 'dark'|'accent'|'grey'}] плашки-выводы над группами.
frame: {'from': i, 'to': j, 'note': 'текст'} пунктирная рамка вокруг худших/лучших и выноска под осью.
callout: {'cat': i, 'series'?: имя, 'text': '+68% г/г', 'sub'?: 'Корпоративные'} выноска с линией к столбцу.
side: {'title': 'И что из этого', 'text': '...', 'note'?: '...'} врезка справа на треть ширины.
cagr: {'from': i, 'to': j, 'text': '+12% в год'} стрелка над столбцами.
pair_deltas: при двух сериях скобка со стрелкой над каждой парой и плашка разницы (второе минус первое),
             зелёная или красная по up_is_good; delta_unit: 'п.п.' и т. п.
title, sub: заголовок панели и единицы внутри рисунка; несколько панелей в ряд собирать через X.panels.
top_min: верх поля графика не выше этого y (ставит X.panels, чтобы оси панелей совпали).
value_text: свои подписи значений по категориям (одна серия), когда число на шкале условное: «≈9 мес.», «5–6 дней».
```

## Пример

`columns_period` (кадр: `python3 tests/demo.py columns_period`)

```python
def columns_period():
    yrs = [str(y) for y in range(2012, 2027)]
    vals = [17.5, 12.1, 9.3, 9.4, 8.8, 10.7, 13.2, 14.0, 13.8, 13.7, 15.8, 15.5, 16.3, 16.8, 17.1]
    return X.columns(yrs, {'IRR': vals}, highlight=[2, 3, 4], decimals=1,
                     frame={'from': 2, 'to': 4, 'note': 'Без трёх худших лет доходность была бы 14,5% вместо 13,7%'},
                     side={'title': 'Средняя доходность', 'text': '13,7% за 2012–2026, 14,5% без 2014–2016'})
```

  смотреть: https://www.bcg.com/publications/2026/how-the-factory-of-the-future-reshapes-manufacturing
