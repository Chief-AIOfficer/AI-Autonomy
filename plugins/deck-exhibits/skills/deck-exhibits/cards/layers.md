# Слои стека (`layers`)

> Собрано `build_docs.py` из `catalog.py` и кода функции. Руками не править.

**Что говорит слайд.** Уровни стека пирамидой и примеры справа, выровненные по слоям.

**Брать, когда в ТЗ:** «технологический стек», «уровни автоматизации», «карта игроков по уровням».

**Не брать, если:** слоёв больше 5.

**Данные на вход:** layers [{name, inner, right: [примеры]}] сверху вниз.

**Потолки:** слоёв 2–5.

**Типы сообщения:** Логика и состав.

## Правила оформления

- Примеры плашками-именами; логотипы только если есть файлы и права.

## Вызов

```python
import sys; sys.path.insert(0, SKILL_DIR)   # SKILL_DIR: папка скилла, см. SKILL.md
import exhibits as X
ex = X.layers(layers_, *, title_right=None, theme=None, mode='показ', width=None)
ex.svg        # строка SVG, ширина 1168 px при 1:1 со слайдом 1280×720
ex.warnings   # наложения, выход за край, мелкий кегль: пусто = чисто
```

## Параметры (из кода)

```
Слои стека пирамидой слева и ряды справа (компании, системы, примеры), выровненные по слоям.

layers_: [{'name': 'Корпоративный уровень', 'inner': 'ERP, бизнес-системы', 'right': ['1С', 'SAP', 'Галактика'], 'hl'?: True}] сверху вниз, 2–5.
right: плашки в один-два ряда; не влезли: FitError. hl: слой, о котором заголовок, получает акцент, остальные серые.
```

## Пример

`layers` (кадр: `python3 tests/demo.py layers`)

```python
def layers():
    return X.layers([{'name': 'Корпоративный уровень', 'inner': 'ERP', 'right': ['1С', 'SAP', 'Галактика', 'Directum']},
                     {'name': 'Управление процессом', 'inner': 'SCADA, РСУ', 'right': ['Siemens', 'Элеси', 'Текон', 'Prosoft']},
                     {'name': 'Интеграция', 'inner': 'Мониторинг и наладка', 'right': ['ГК ИТЕК', 'Инкомсистем', 'АТГ']},
                     {'name': 'Приборы', 'inner': 'Датчики, приводы, расходомеры', 'right': ['Метран', 'ЭлМетро', 'Овен', 'Теплоприбор']}],
                    title_right='Примеры компаний')
```
