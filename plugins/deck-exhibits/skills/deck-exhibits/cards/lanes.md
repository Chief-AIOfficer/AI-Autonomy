# Дорожки событий (`lanes`)

> Собрано `build_docs.py` из `catalog.py` и кода функции. Руками не править.

**Что говорит слайд.** Хронология по нескольким объектам: дорожка на объект, цвет маркера означает тип события.

**Брать, когда в ТЗ:** «как развивалось в разных странах», «хронология», «события по командам».

**Не брать, если:** событий на дорожке больше 8; нужны длительности (gantt).

**Данные на вход:** lanes [{name, note, events: [(позиция 0–1, дата, подпись, тип)]}], kinds.

**Потолки:** дорожек до 5.

**Типы сообщения:** Время и план.

## Правила оформления

- Слева серый блок с выводом по дорожке.

## Вызов

```python
import sys; sys.path.insert(0, SKILL_DIR)   # SKILL_DIR: папка скилла, см. SKILL.md
import exhibits as X
ex = X.lanes(lanes_, *, scale=None, kinds=None, label_w=230, theme=None, mode='показ', width=None)
ex.svg        # строка SVG, ширина 1168 px при 1:1 со слайдом 1280×720
ex.warnings   # наложения, выход за край, мелкий кегль: пусто = чисто
```

## Параметры (из кода)

```
Дорожки событий: малые кратные таймлайнов, по дорожке на страну, команду или продукт; цвет маркера = тип события.

lanes_: [{'name': 'Индия', 'note': 'От общенационального к точечному', 'events': [(0.1, '25 мар', 'Общий карантин', 'start'), ...]}]
        позиция события от 0 до 1 по шкале; дата и подпись над осью.
kinds: {'start': ('Начало ограничений', 'accent_dark'), 'ease': ('Смягчение', 'accent_light')}
```

## Пример

`lanes` (кадр: `python3 tests/demo.py lanes`)

```python
def lanes():
    k = {'start': ('Ограничения введены', 'accent_dark'), 'ease': ('Смягчение', 'accent_light'), 'local': ('Местные меры', 'accent')}
    return X.lanes([{'name': 'Москва', 'note': 'От общих мер к точечным', 'events': [(0.03, '25 мар', 'Общий режим', 'start'), (0.2, '14 апр', 'Продление', 'start'),
                     (0.38, '04 мая', 'Смягчение в районах', 'ease'), (0.62, '01 июн', 'Дальнейшее смягчение', 'ease'), (0.92, '06 июл', 'Точечные меры', 'local')]},
                    {'name': 'Казань', 'note': 'Повторный режим после второй волны', 'events': [(0.05, '23 мар', 'Общий режим', 'start'), (0.45, '15 мая', 'Смягчение', 'ease'),
                     (0.75, '20 июн', 'Новые меры', 'local'), (0.95, '17 июл', 'Усиление', 'local')]}], kinds=k)
```
