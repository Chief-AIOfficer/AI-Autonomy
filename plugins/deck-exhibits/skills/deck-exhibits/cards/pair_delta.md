# Пара с разницей (`pair_delta`)

> Собрано `build_docs.py` из `catalog.py` и кода функции. Руками не править.

**Что говорит слайд.** Насколько одно больше другого: два столбца и крупная разница.

**Брать, когда в ТЗ:** «на 24 п.п. выше», «вдвое больше», «мы против рынка»; 1–3 показателя, у каждого два числа и своя единица; главное сообщение это величина разницы.

**Не брать, если:** объектов больше двух (bar_ranked, columns); показатели в одной единице на многих объектах (dumbbell).

**Данные на вход:** панели [{title, sub, a: (подпись, число), b: (подпись, число)}], 1–3 панели.

**Потолки:** панелей 1–3.

**Типы сообщения:** Разница и мост, Сравнение и рейтинг.

## Правила оформления

- Позитивный и негативный исход рядом: две панели, у негативной tone="bad" (столбец и разница цветом потери); ширина столбцов и зазор общие, считаются сами (замечание 11.10).
- У каждой панели своя шкала: показатели разные, общая ось врёт.
- Разница крупным кеглем, акцентом; она и есть сообщение.

## Параметры (из кода)

```
Насколько одно больше другого или «было → стало»: два столбца, пунктир от верхушек и крупная разница.

panels: [{'title': 'Удовлетворённость', 'sub': 'п.п.', 'a': ('Финтех', 39), 'b': ('Банки', 15), 'decimals'?: 1,
          'hl'?: 'a'|'b', 'delta'?: 'в 120 раз', 'delta_sub'?: 'быстрее'}]
1–3 панели рядом, у каждой своя шкала (так честнее, чем общая ось для разных единиц).
Было → стало: a = ('Было', …), b = ('Стало', …), hl='b' (акцент на результате), стрелка идёт от «было» к «стало».
delta: своя подпись разницы, когда арифметика не говорит главного («в 120 раз» вместо «−119»); delta_sub строкой под ней.
sub кончается на «%» (единица панели проценты): разница без своей подписи получает «п.п.» сама.
tone: 'bad' красит выделенный столбец и разницу в цвет потери (негативный исход рядом с позитивным).
```

## Пример

`pair_delta` (кадр: `python3 tests/demo.py pair_delta`)

```python
def pair_delta():
    return X.pair_delta([{'title': 'Чистая удовлетворённость', 'sub': 'п.п.', 'a': ('Финтех', 39), 'b': ('Банки', 15)},
                         {'title': 'Доверие', 'sub': 'шкала 1–10', 'a': ('Финтех', 8.3), 'b': ('Банки', 7.9), 'decimals': 1}])
```
