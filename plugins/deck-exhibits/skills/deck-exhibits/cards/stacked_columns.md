# Стековые столбцы (`stacked_columns`)

> Собрано `build_docs.py` из `catalog.py` и кода функции. Руками не править.

**Что говорит слайд.** Как растёт целое и за счёт каких частей.

**Брать, когда в ТЗ:** «рынок по сегментам по годам», «выручка по направлениям», темпы роста.

**Не брать, если:** важна только доля (stacked_100); сегментов больше 6.

**Данные на вход:** периоды + {сегмент: значения} снизу вверх; steps: темпы между столбцами; seg_growth: темпы сегментов.

**Потолки:** столбцов 2–10, сегментов до 6.

**Типы сообщения:** Структура целого, Динамика.

## Правила оформления

- Итог над столбцом, темпы стрелкой над столбцами, рост сегментов кружками справа.
- Тёмный низ: базовый сегмент внизу, самый тёмный.

## Вызов

```python
import sys; sys.path.insert(0, SKILL_DIR)   # SKILL_DIR: папка скилла, см. SKILL.md
import exhibits as X

ex.svg        # строка SVG, ширина 1168 px при 1:1 со слайдом 1280×720

```

## Параметры (из кода)

```
Стековые столбцы по периодам: как растёт целое и из чего. Итог над столбцом, темпы между столбцами.

segments: {имя: [значения]} снизу вверх; подписи сегментов справа от последнего столбца.
steps: ['+15%', '+13%', ...] темп между соседними столбцами (n-1 штук), стрелка над столбцами.
seg_growth: {имя: '+18%'} кружки темпа по сегментам справа, цвет как у сегмента.
```

## Пример

`stacked_columns` (кадр: `python3 tests/demo.py stacked_columns`)

```python
def stacked_columns():
    return X.stacked_columns(['2021', '2022', '2023', '2024', '2025'],
                             {'Платежи': [100, 128, 158, 188, 222], 'Кредиты': [61, 65, 72, 86, 103], 'Инвестиции': [51, 45, 39, 54, 74],
                              'Депозиты': [16, 21, 24, 31, 41], 'Страхование': [29, 35, 41, 55, 64]},
                             steps=['+15%', '+13%', '+24%', '+22%'],
                             seg_growth={'Платежи': '+18%', 'Кредиты': '+20%', 'Инвестиции': '+38%', 'Депозиты': '+30%', 'Страхование': '+16%'})
```
