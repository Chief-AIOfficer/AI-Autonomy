# Гант (`gantt`)

> Собрано `build_docs.py` из `catalog.py` и кода функции. Руками не править.

**Что говорит слайд.** Что и когда: полосы работ, вехи, «сегодня».

**Брать, когда в ТЗ:** «план-график», «по неделям», «дорожная карта», «сроки», «когда договор».

**Не брать, если:** работ больше 14 (группировать); сроки не важны (stages).

**Данные на вход:** periods, tasks [{label, start, end, kind, note, group}], milestones, today.

**Потолки:** работ до 14, вех до 5.

**Типы сообщения:** Время и план.

## Правила оформления

- Наши работы тёмным, работы заказчика серым, ключевая акцентом.
- Вехи ромбами внизу с пунктиром вверх.

## Вызов

```python
import sys; sys.path.insert(0, SKILL_DIR)   # SKILL_DIR: папка скилла, см. SKILL.md
import exhibits as X
ex = X.gantt(periods, tasks, *, label_w=300, milestones=None, today=None, period_label=None, groups=None, theme=None, mode='показ', width=None)
ex.svg        # строка SVG, ширина 1168 px при 1:1 со слайдом 1280×720
ex.warnings   # наложения, выход за край, мелкий кегль: пусто = чисто
```

## Параметры (из кода)

```
Дорожная карта Гантом: полосы работ по периодам, вехи ромбами, «сегодня» пунктиром.

periods: ['Нед 1', ..., 'Нед 8'] или месяцы; координаты задач в индексах периодов, дробные можно.
tasks: [{'label': 'Обследование', 'start': 0, 'end': 2, 'kind'?: 'main'|'side'|'accent', 'note'?: '2 недели', 'group'?: 'Наши работы'}]
milestones: [(4.5, 'Решение о закупке')]; today: позиция пунктира.
```

## Пример

`gantt` (кадр: `python3 tests/demo.py gantt`)

```python
def gantt():
    return X.gantt([f'Нед {k}' for k in range(1, 9)],
                   [{'label': 'Запуск: план, доступы, люди', 'start': 0, 'end': 1, 'group': 'Наши работы'},
                    {'label': 'Данные: выгрузки, справочники', 'start': 0, 'end': 3, 'kind': 'accent', 'group': 'Наши работы'},
                    {'label': 'Юнит-экономика: методика и MVP', 'start': 1, 'end': 5, 'group': 'Наши работы'},
                    {'label': 'Архитектура данных и ИИ', 'start': 4, 'end': 7, 'group': 'Наши работы'},
                    {'label': 'Закупка: предложения', 'start': 3, 'end': 3.7, 'kind': 'side', 'note': '5 рабочих дней', 'group': 'Заказчик'},
                    {'label': 'Закупка: договор', 'start': 4, 'end': 6, 'kind': 'side', 'note': 'после итогов', 'group': 'Заказчик'}],
                   milestones=[(1, 'План'), (3, 'Картина данных'), (5, 'Короткий список'), (8, 'Итог и решение')], today=0.3)
```
