# Карточки показателей (`kpi_cards`)

> Собрано `build_docs.py` из `catalog.py` и кода функции. Руками не править.

**Что говорит слайд.** Несколько показателей сразу; просевший выделен.

**Брать, когда в ТЗ:** «все показатели растут, кроме», «дашборд», «состояние на месяц».

**Не брать, если:** показателей больше 6 (table).

**Данные на вход:** cards [{name, value, delta, trend, bad?}].

**Потолки:** карточек 2–6 (Миллерд: 4–6).

**Типы сообщения:** Дашборд.

## Правила оформления

- Под карточками разбор причины одним из приёмов (bar_ranked, points).

## Вызов

```python
import sys; sys.path.insert(0, SKILL_DIR)   # SKILL_DIR: папка скилла, см. SKILL.md
import exhibits as X
ex = X.kpi_cards(cards, *, theme=None, mode='показ', width=None)
ex.svg        # строка SVG, ширина 1168 px при 1:1 со слайдом 1280×720
ex.warnings   # наложения, выход за край, мелкий кегль: пусто = чисто
```

## Параметры (из кода)

```
Дашборд: 2–6 карточек показателей со спарклайном; просевший показатель выделен.

cards: [{'name': 'Выручка', 'value': '4,2 млн ₽', 'delta': '+18% к прошлому месяцу', 'trend': [..], 'bad'?: True, 'good_is_up'?: True}]
```
