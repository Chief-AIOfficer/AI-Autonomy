# Шкала вариантов (`spectrum`)

> Собрано `build_docs.py` из `catalog.py` и кода функции. Руками не править.

**Что говорит слайд.** Варианты на шкале от одного края к другому, у каждого суть и следствие.

**Брать, когда в ТЗ:** «варианты партнёрства», «от своего к чужому», «уровни интеграции», «где мы сейчас».

**Не брать, если:** варианты не упорядочены по одной оси (table).

**Данные на вход:** options [{title, text, effect с **ключом**}], ends, current, verdict.

**Потолки:** вариантов 3–5.

**Типы сообщения:** Варианты на шкале, Процесс и этапы.

## Правила оформления

- current отмечает вариант, где мы сейчас; verdict полосой внизу.

## Вызов

```python
import sys; sys.path.insert(0, SKILL_DIR)   # SKILL_DIR: папка скилла, см. SKILL.md
import exhibits as X
ex = X.spectrum(options, *, ends=('Всё делаем сами', 'Всё отдаём партнёру'), verdict=None, current=None, theme=None, mode='показ', width=None)
ex.svg        # строка SVG, ширина 1168 px при 1:1 со слайдом 1280×720
ex.warnings   # наложения, выход за край, мелкий кегль: пусто = чисто
```

## Параметры (из кода)

```
Шкала вариантов: от одного края к другому, варианты метками-указателями, под каждым суть и следствие.

options: [{'title': 'Свой продукт', 'text': 'Всё разрабатываем внутри', 'effect': '**Полный контроль**, но медленно'}] 3–5.
current: индекс варианта, где мы сейчас (метка акцентом).
verdict: вывод полосой внизу.
```

## Пример

`spectrum` (кадр: `python3 tests/demo.py spectrum`)

```python
def spectrum():
    return X.spectrum([{'title': 'Всё своё', 'text': 'Систему и приложения делаем сами', 'effect': '**Полный контроль**, но медленно и дорого'},
                       {'title': 'Готовая платформа', 'text': 'Стандартная платформа поставщика', 'effect': '**Быстрее разработка**, меньше гибкости'},
                       {'title': 'Зеркало приложений', 'text': 'Сервисы партнёров внутри нашего продукта', 'effect': '**Привычные сервисы**, свои реже нужны'},
                       {'title': 'Данные партнёру', 'text': 'Партнёр строит услуги на наших данных', 'effect': '**Лучший опыт клиента**, но теряем данные'},
                       {'title': 'Всё у партнёра', 'text': 'Весь цифровой слой у поставщика', 'effect': '**Риск стать трубой** для чужих сервисов'}],
                      verdict='Выигрывает тот, кто держит клиента, технологию и данные', current=2)
```
