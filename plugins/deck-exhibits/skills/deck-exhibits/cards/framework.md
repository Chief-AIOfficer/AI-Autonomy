# Рамка из блоков (`framework`)

> Собрано `build_docs.py` из `catalog.py` и кода функции. Руками не править.

**Что говорит слайд.** Разделы (зачем, что, как) слева, модули строками, действия справа.

**Брать, когда в ТЗ:** «фреймворк», «модули и действия», «из чего состоит программа», «рамка управления рисками».

**Не брать, если:** строк больше 9; нет иерархии разделов (table).

**Данные на вход:** sections [{label, icon?, rows: [{name, text с **ключами**}]}].

**Потолки:** разделов до 5, строк до 9.

**Типы сообщения:** Логика и состав, Риски, Рекомендации.

## Правила оформления

- Тон разделов от тёмного к светлому: что раньше и важнее, то темнее.

## Вызов

```python
import sys; sys.path.insert(0, SKILL_DIR)   # SKILL_DIR: папка скилла, см. SKILL.md
import exhibits as X
ex = X.framework(sections, *, head=('', ''), theme=None, mode='показ', width=None)
ex.svg        # строка SVG, ширина 1168 px при 1:1 со слайдом 1280×720
ex.warnings   # наложения, выход за край, мелкий кегль: пусто = чисто
```

## Параметры (из кода)

```
Рамка из блоков: разделы слева (Зачем, Что, Как), модули строками, действия справа с жирными ключами.

sections: [{'label': 'Зачем', 'icon'?: 'compass', 'rows': [{'name': 'Таксономия рисков', 'text': '**Определить** категории…'}]}]
Тон разделов от тёмного к светлому: что раньше и важнее, то темнее.
head: подписи колонок (модули, действия).
```
