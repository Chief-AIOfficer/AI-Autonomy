# Столпы (`pillars`)

> Собрано `build_docs.py` из `catalog.py` и кода функции. Руками не править.

**Что говорит слайд.** Три-пять направлений колонками: иконка, суть, эффект; общий итог внизу.

**Брать, когда в ТЗ:** «три направления», «столпы стратегии», «за счёт чего закроем разрыв», «по каждому направлению темы».

**Не брать, если:** направлений больше 5; нет параллельной структуры (points).

**Данные на вход:** columns [{icon, title, text?, items?: [(тема, строка)], effect?, effect_note?}], total.

**Потолки:** столпов 2–5; тем на столп до 4.

**Типы сообщения:** Направления, Рекомендации.

## Правила оформления

- Эффект цифрой под каждым столпом, сумма плашкой внизу.
- Сетка тем: карточки выравниваются по рядам.

## Вызов

```python
import sys; sys.path.insert(0, SKILL_DIR)   # SKILL_DIR: папка скилла, см. SKILL.md
import exhibits as X
ex = X.pillars(columns, *, total=None, icon_style='ring', theme=None, mode='показ', width=None)
ex.svg        # строка SVG, ширина 1168 px при 1:1 со слайдом 1280×720
ex.warnings   # наложения, выход за край, мелкий кегль: пусто = чисто
```

## Параметры (из кода)

```
Столпы: 3–5 направлений колонками. Иконка, заголовок, текст или пункты, эффект цифрой, общий итог внизу.

columns: [{'icon', 'title', 'text'?, 'items'?: [('Тема', 'одна строка')], 'effect'?: '+5 млн ₽', 'effect_note'?: 'эффект в год'}]
icon_style: 'ring' (обводка) или 'solid' (тёмный круг).
total: 'Вместе: +14 млн ₽ в год, разрыв до цели закрыт' плашка внизу.
```

                     total='Вместе: +14 млн ₽ в год, разрыв до цели 2026 закрыт')
