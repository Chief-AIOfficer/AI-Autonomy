# Две группы по показателям (`group_delta`)

> Собрано `build_docs.py` из `catalog.py` и кода функции. Руками не править.

**Что говорит слайд.** Где одна группа отстаёт от другой: по каждому показателю плашка разницы.

**Брать, когда в ТЗ:** «лучшие и остальные», «лидеры против середняков», «где отстаём»; 2–5 показателей в разных единицах, сообщение про то, в каких показателях разрыв.

**Не брать, если:** групп больше двух (table); показатель один (pair_delta).

**Данные на вход:** metrics [{title, sub, values: (a, b)}], groups (имя a, имя b).

**Потолки:** показателей 2–5.

**Типы сообщения:** Разница и мост, Сравнение и рейтинг.

## Правила оформления

- Разница в % от первой группы по умолчанию; красная плашка там, где отстаём, серая при нуле.

## Вызов

```python
import sys; sys.path.insert(0, SKILL_DIR)   # SKILL_DIR: папка скилла, см. SKILL.md
import exhibits as X
ex = X.group_delta(metrics, groups, *, decimals=0, pct=True, bad_if_negative=True, theme=None, mode='показ', width=None)
ex.svg        # строка SVG, ширина 1168 px при 1:1 со слайдом 1280×720
ex.warnings   # наложения, выход за край, мелкий кегль: пусто = чисто
```

## Параметры (из кода)

```
Две группы по нескольким показателям и разница между ними плашкой: где отстаём.

metrics: [{'title': 'Велокультура', 'sub': 'взрослые с велосипедом, %', 'values': (59, 33), 'decimals'?: 2}]
groups: ('Лидеры', 'Середняки'). Разница в % от первой (pct=True) или в единицах.
```

## Пример

`group_delta` (кадр: `python3 tests/demo.py group_delta`)

```python
def group_delta():
    return X.group_delta([{'title': 'Конверсия', 'sub': 'заявка в выдачу, %', 'values': (59, 33)},
                          {'title': 'Скорость', 'sub': 'заявок в день на менеджера', 'values': (0.43, 0.28), 'decimals': 2},
                          {'title': 'Повторные', 'sub': 'клиенты с 2+ продуктами на 1000', 'values': (1.59, 0.71), 'decimals': 2},
                          {'title': 'NPS', 'sub': 'по опросу за квартал', 'values': (23, 23)}],
                         ('Лучшие отделения', 'Остальные отделения'))
```
