# Центр и результаты вокруг (`hub`)

> Собрано `build_docs.py` из `catalog.py` и кода функции. Руками не править.

**Что говорит слайд.** Человек или объект в центре, вокруг 4–10 результатов или умений двумя колонками; связи ортогональные.

**Брать, когда в ТЗ:** «что получит слушатель», «что изменится для тебя», «вокруг клиента», «модули вокруг участника», вход в программу или курс.

**Не брать, если:** пункты равноправны без общего центра (points); есть порядок шагов и важен ход (stages); пунктов больше 10.

**Данные на вход:** center {title, sub?, icon?}; items [{n?, title, text с **ключом**}]; split: сколько слева; heads: подписи колонок.

**Потолки:** пунктов 4–10 (техника раскладки: две колонки); текст пункта до 3 строк.

**Типы сообщения:** Логика и состав, Направления.

## Правила оформления

- Слева и справа можно развести фазы (до и после события), подписи колонок через heads.
- Связи от карточки к шине и от шины к центру под прямым углом, косых линий нет.
- Порядок чтения сверху вниз по колонкам: номера n помогают, когда пункты это шаги.

## Вызов

```python
import sys; sys.path.insert(0, SKILL_DIR)   # SKILL_DIR: папка скилла, см. SKILL.md
import exhibits as X
ex = X.hub(center, items, *, split=None, heads=None, theme=None, mode='показ', width=None)
ex.svg        # строка SVG, ширина 1168 px при 1:1 со слайдом 1280×720
ex.warnings   # наложения, выход за край, мелкий кегль: пусто = чисто
```

## Параметры (из кода)

```
Центр и результаты вокруг: человек или объект посередине, пункты двумя колонками, связи ортогональными линиями.

center: {'title': 'Ты', 'sub'?: 'руководитель в поиске работы', 'icon'?: 'user'}.
items: [{'n'?: '1', 'title': 'Роль', 'text': 'Оцениваешь, **какая роль** подходит'}] 4–10 штук; слева первые split, справа остальные.
heads: подписи колонок над пунктами, например ('До отклика', 'После отклика').
Связи идут от карточки к вертикальной шине и от шины к центру: косых линий нет (правило стиля v3).
```

## Пример

`hub_steps` (кадр: `python3 tests/demo.py hub_steps`)

```python
def hub_steps():
    return X.hub({'title': 'Ты', 'sub': 'руководитель в поиске работы', 'icon': 'user'},
                 [{'n': 1, 'title': 'Роль', 'text': 'Оцениваешь, **какая роль подходит**, по портфолио и склонностям'},
                  {'n': 2, 'title': 'Мастер-резюме', 'text': 'Собираешь резюме, **которое продаёт роль** за 30 секунд'},
                  {'n': 3, 'title': 'Вакансия', 'text': 'Читаешь объявление **между строк**'},
                  {'n': 4, 'title': 'Компания', 'text': 'Узнаёшь, **кто заказчик роли** и что в компании болит'},
                  {'n': 5, 'title': 'Отклик', 'text': 'Пишешь письмо **своим голосом**'},
                  {'n': 6, 'title': 'Встреча', 'text': 'Приходишь **с гипотезами**, а не с вопросами'}],
                 split=3, heads=('До отклика', 'После отклика'))
```
