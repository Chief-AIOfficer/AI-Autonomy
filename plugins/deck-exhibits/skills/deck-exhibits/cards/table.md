# Таблица-график (`table`)

> Собрано `build_docs.py` из `catalog.py` и кода функции. Руками не править.

**Что говорит слайд.** Объекты по нескольким критериям: таблица, которая читается как график.

**Брать, когда в ТЗ:** «по каждому кейсу», «стадия внедрения», «оценка вариантов», «таблица с цифрами и пояснениями».

**Не брать, если:** объектов больше 16 (приложение); один критерий (bar_ranked).

**Данные на вход:** колонки [{key, title, type: text|num|bar|harvey|tone|stack|bars}] + строки, группы строк.

**Потолки:** строк до 16; текстовых колонок 1–2.

**Типы сообщения:** Оценка вариантов, Сравнение и рейтинг.

## Правила оформления

- Числа как столбики в ячейках (bar), стадия как шар Харви (harvey), оценка тоном (tone).
- Группы строк подписаны слева, между группами черта.
- Ключевая строка жирным через hl.

## Вызов

```python
import sys; sys.path.insert(0, SKILL_DIR)   # SKILL_DIR: папка скилла, см. SKILL.md
import exhibits as X
ex = X.table(columns, rows, *, group_w=None, legend=None, legend_title=None, harvey_levels=4, row_lines=True, row_h=None, theme=None, mode='показ', width=None)
ex.svg        # строка SVG, ширина 1168 px при 1:1 со слайдом 1280×720
ex.warnings   # наложения, выход за край, мелкий кегль: пусто = чисто
```

## Параметры (из кода)

```
Таблица-график. Колонки разных видов, строки можно группировать.

columns: [{'key', 'title', 'type', 'width'?, ...}], type:
  'text'   текст, **жирные ключи** допустимы; 'bold': True для колонки-имени
  'num'    число: 'decimals', 'unit', 'sign'
  'bar'    столбик в ячейке на сером треке, 'max' (по умолчанию максимум колонки), 'fill' роль цвета, 'decimals', 'unit'
  'harvey' шар Харви, значение 0–4
  'tone'   кружок цвета шкалы одного тона, 'scale': (min, max), 'show': показывать число
  'stack'  мини-стек из частей, 'parts': [имена], значение: список чисел; легенда частей сверху
  'bars'   мини-группа горизонтальных полосок (по одной на серию), 'parts': [имена], значение: список
  'kpi'    ключевое число строки крупно акцентом («в 120 раз», «−80%», «83%»): цифры кейсов не тонут в тексте
  'mark'   категория буквой в залитой клетке, 'marks': {'Р': 'accent', 'С': 'accent_pale'} (роли RACI: решает, согласует);
           это категории, не степень, поэтому не шары Харви
rows: [{key: значение, 'group'?: 'Имя группы', 'hl'?: True}]; group рисует колонку групп слева с чертой между группами.
legend: [('harvey', 'Пилот', 3)] для шаров (первым элементом вид колонки: 'harvey' или роль цвета для tone); рисуется сверху справа.
legend_title: что меряет шкала («Вклад»), пишется перед легендой; без него «малый» и «основной» читаются как разные измерения.
harvey_levels: сколько ступеней у шаров (4 четверти или 3 трети). Легенда должна идти без пропусков: 0 или 1, затем подряд до harvey_levels.
row_h: наименьшая высота строки; для текстовой таблицы на весь слайд, чтобы строки не жались к верху.
```

`table_harvey` (кадр: `python3 tests/demo.py table_harvey`)

```python
def table_harvey():
    cols = [{'key': 'case', 'title': 'Применение', 'type': 'text', 'width': 260},
            {'key': 'st', 'title': 'Стадия', 'type': 'harvey'},
            {'key': 'ex', 'title': 'Пример', 'type': 'text'}]
    rows = [{'group': 'Сжатие', 'case': 'Ассистент для сотрудников', 'st': 4, 'ex': 'Несколько банков дали сотрудникам ассистента для разбора документов'},
            {'group': 'Сжатие', 'case': 'Сводка для кредитного решения', 'st': 1, 'ex': 'Банк развития пробует ИИ для поиска и выводов по документам'},
            {'group': 'Тексты', 'case': 'Черновик кредитного меморандума', 'st': 3, 'ex': 'Крупные банки пилотируют агентов, которые собирают первичный меморандум'},
            {'group': 'Тексты', 'case': 'Проверка качества данных', 'st': 2, 'ex': 'Банк проверяет **источники данных** и помечает вероятные ошибки'}]
    return X.table(cols, rows, legend=[('harvey', 'Идея', 1), ('harvey', 'Проба', 2), ('harvey', 'Пилот', 3), ('harvey', 'Внедрено', 4)])
```

## Образцы (публичные слайды, описаны словами)

- `D_scorecard_01` Datawrapper 2025: Таблица со встроенными столбцами. В ячейках горизонтальные столбики, сортировка по первой колонке, три цвета для трёх состояний и итог справа. Таблица читается как график.
  смотреть: https://www.datawrapper.de/blog/fix-my-chart-approval-ratings
- `B2_scorecard_01` McKinsey 2025: Таблица с 100% столбиком и мини-диаграммами по этапам. каждая строка это вариант применения, справа этапы с малыми столбиками и процентами. Группы строк разделены тонкой линией, слева иконка группы.
  смотреть: https://iacpm.org/wp-content/uploads/2025/03/IACPM-McKinsey-Gen-AI-Webinar-2025.pdf
- `B2_scorecard_02` McKinsey 2025: Таблица кейсов с шарами Харви по стадиям. шар Харви показывает стадию внедрения, рядом пример одной строкой, группы подписаны слева. Легенда шаров в правом верхнем углу.
  смотреть: https://iacpm.org/wp-content/uploads/2025/03/IACPM-McKinsey-Gen-AI-Webinar-2025.pdf
- `B2_compare_01` McKinsey 2025: Уровни приоритета: описание слева, столбцы по типам банков справа. каждая строка таблицы заканчивается группой горизонтальных столбцов, цвета означают тип банка. Ключевой процент в строке выделен цветом.
  смотреть: https://iacpm.org/wp-content/uploads/2025/03/IACPM-McKinsey-Gen-AI-Webinar-2025.pdf
