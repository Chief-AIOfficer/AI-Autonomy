# Столбцы 100% (`stacked_100`)

> Собрано `build_docs.py` из `catalog.py` и кода функции. Руками не править.

**Что говорит слайд.** Как меняется структура по группам или периодам.

**Брать, когда в ТЗ:** «доля», «структура», «распределение ответов», «по размеру вложений», «сдвиг моделей».

**Не брать, если:** важен размер целого (stacked_columns); одна разбивка (share_bar).

**Данные на вход:** категории + {сегмент: значения} снизу вверх; normalize для счётных данных.

**Потолки:** столбцов 2–8, сегментов до 6.

**Типы сообщения:** Структура целого.

## Правила оформления

- Подписи сегментов слева у первого столбца, легенды нет.
- Выделенный сегмент тёмный, остальные серые; без выделения шкала одного тона.
- links соединяют сегменты между периодами: видно, как растёт и падает доля.
- footer даёт строку итогов под столбцами (индекс, база).

## Вызов

```python
import sys; sys.path.insert(0, SKILL_DIR)   # SKILL_DIR: папка скилла, см. SKILL.md
import exhibits as X
ex = X.stacked_100(categories, segments, *, highlight=(), normalize=True, links=False, footer=None, decimals=0, height=380, head=None, theme=None, mode='показ', width=None)
ex.svg        # строка SVG, ширина 1168 px при 1:1 со слайдом 1280×720
ex.warnings   # наложения, выход за край, мелкий кегль: пусто = чисто
```

## Параметры (из кода)

```
Столбцы 100%: как меняется структура по группам или периодам. Подписи серий слева, легенды нет.

segments: {имя: [значения по категориям]} в порядке снизу вверх.
normalize: пересчитать в доли (для счётных данных, где сумма не 100).
links: светлые связки между соседними столбцами для выделенных сегментов (видно, как растёт и падает доля).
footer: {'title': 'Индекс зрелости', 'values': [1.9, 2.2, ...], 'decimals': 1} строка под столбцами.
head: подпись над столбцами (например, «% респондентов»).
```

## Пример

`stacked_100` (кадр: `python3 tests/demo.py stacked_100`)

```python
def stacked_100():
    return X.stacked_100(['до 1 млн', '1–5 млн', '5–10 млн', '10–25 млн', '25–50 млн', 'от 50 млн'],
                         {'Эффекта почти нет': [8, 2, 0, 2, 3, 0], 'Эффект трудно посчитать': [30, 19, 16, 11, 5, 4],
                          'Эффект меньше 5% EBIT': [40, 42, 46, 33, 28, 24], 'Эффект больше 5% EBIT': [22, 38, 39, 55, 64, 72]},
                         highlight=['Эффект больше 5% EBIT'], head='% компаний по размеру вложений в ответственный ИИ',
                         footer={'title': 'Индекс зрелости', 'values': [1.9, 2.2, 2.4, 2.4, 2.8, 2.8]})
```

`stacked_100_links` (кадр: `python3 tests/demo.py stacked_100_links`)

```python
def stacked_100_links():
    return X.stacked_100(['2005', '2015', '2025'], {'Региональные': [5, 6, 10], 'Прочие': [5, 8, 6], 'Глобальные': [10, 6, 4]},
                         highlight=['Региональные', 'Глобальные'], links=True, head='20 крупнейших банков по модели бизнеса')
```
