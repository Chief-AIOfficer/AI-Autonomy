# Гантели и «было → стало» (`dumbbell`)

> Собрано `build_docs.py` из `catalog.py` и кода функции. Руками не править.

**Что говорит слайд.** Два значения на строку: где разрыв большой, где его нет; или сдвиг от «до» к «после».

**Брать, когда в ТЗ:** «лидеры и остальные по инициативам», «до и после», «с мерой и без», шкала вокруг нуля; одна единица на все строки, строк больше шести.

**Не брать, если:** значение одно (bar_ranked); показатели в разных единицах (group_delta).

**Данные на вход:** [(подпись, значение до или группы 1, значение после или группы 2)].

**Потолки:** строк 2–15; зон с выводами справа до 4.

**Типы сообщения:** Связь и сдвиг, Сравнение и рейтинг.

## Правила оформления

- style="dots" для двух групп, style="arrow" для сдвига «было → стало».
- zero рисует пунктир «равенства», zones дают выводы справа на группу строк.

## Вызов

```python
import sys; sys.path.insert(0, SKILL_DIR)   # SKILL_DIR: папка скилла, см. SKILL.md
import exhibits as X
ex = X.dumbbell(rows, *, names=('до', 'после'), unit='', decimals=0, style='dots', scale=None, zero=None, zones=None, ticks=None, theme=None, mode='показ', width=None)
ex.svg        # строка SVG, ширина 1168 px при 1:1 со слайдом 1280×720
ex.warnings   # наложения, выход за край, мелкий кегль: пусто = чисто
```

## Параметры (из кода)

```
Два значения на строку и полоса разницы: где разрыв большой, а где его нет. Или «было → стало».

rows: [('Трансформация ИТ', 45, 54), ...] значения в порядке names.
style: 'dots' (гантель: серая и акцентная точка) или 'arrow' (треугольник до, треугольник после, стрелка).
zero: значение, где пунктир «равенства» (для шкал вокруг нуля).
zones: [{'from': i, 'to': j, 'text': '**Ключ** пояснение'}] выводы справа на группу строк.
ticks: значения подписей шкалы сверху; по умолчанию 5 делений.
```

## Пример

`dumbbell` (кадр: `python3 tests/demo.py dumbbell`)

```python
def dumbbell():
    return X.dumbbell([('ИТ-функция на ИИ', 45, 54), ('Кибербезопасность', 41, 46), ('Инфраструктура', 37, 44),
                       ('Таланты и партнёрства', 29, 38), ('Операционная модель', 36, 37), ('Данные как сервис', 35, 34)],
                      names=('остальные', 'лидеры'), unit='%', scale=(0, 100), ticks=[0, 20, 40, 60, 80, 100])
```

`dumbbell_arrow` (кадр: `python3 tests/demo.py dumbbell_arrow`)

```python
def dumbbell_arrow():
    return X.dumbbell([('Продукты питания', 5, 17), ('Химия', -3, 8), ('Деревообработка', -19, 5), ('Авиация', -19, 2),
                       ('Автопром', -22, -1), ('Фарма', -20, -6), ('Электроника', -22, -9)],
                      names=('без автоматизации', 'с автоматизацией'), style='arrow', zero=0, scale=(-25, 22), ticks=[-20, -10, 0, 10, 20],
                      zones=[{'from': 0, 'to': 1, 'text': '**Оставить производство** выгоднее'},
                             {'from': 2, 'to': 4, 'text': '**Модернизация** уравнивает шансы'},
                             {'from': 5, 'to': 6, 'text': '**Перенос** выгоднее даже с автоматизацией'}])
```

## Образцы (публичные слайды, описаны словами)

- `C_compare_07` McKinsey 2026: Два значения на строку: гантели с серой полосой. Две точки на каждую строку (лидеры и остальные), между ними серая полоса разницы. Видно, где разрыв большой, а где его нет.
  смотреть: https://www.mckinsey.com/capabilities/mckinsey-technology/our-insights/mckinsey-global-tech-agenda-2026
- `C_relation_01` BCG 2026: «Было → стало» по строкам и колонка выводов. По строке на отрасль: серый треугольник до, зелёный после, стрелка между ними. Справа сгруппированные выводы по зонам, по центру пунктир нуля.
  смотреть: https://www.bcg.com/publications/2026/how-the-factory-of-the-future-reshapes-manufacturing
