# Этапы со строками и воротами (`stages`)

> Собрано `build_docs.py` из `catalog.py` и кода функции. Руками не править.

**Что говорит слайд.** Этапы шевронами с нарастающим тоном; под ними строки (что делаем, результат, решение); ворота между этапами.

**Брать, когда в ТЗ:** «три этапа», «фазы проекта», «ворота», «stage-gate», «что на выходе каждого этапа»; одна работа как «что выясняем → как проходит → что получаешь» (шевроны без подписей строк).

**Не брать, если:** этапов больше 6; нужны сроки в неделях (gantt).

**Данные на вход:** phases [{title, sub}], rows [{label, cells}], gates [{after, label, items}].

**Потолки:** этапов 2–6 (Миллерд: 4–5); строк до 5.

**Типы сообщения:** Процесс и этапы, Время и план.

## Правила оформления

- Строка решения выделяется акцентом (decision_row).
- Плашка ворот под этапом, который ворота закрывают.

## Вызов

```python
import sys; sys.path.insert(0, SKILL_DIR)   # SKILL_DIR: папка скилла, см. SKILL.md
import exhibits as X
ex = X.stages(phases, *, rows=None, gates=None, label_w=170, decision_row=None, cell_role='small', flat=False, theme=None, mode='показ', width=None)
ex.svg        # строка SVG, ширина 1168 px при 1:1 со слайдом 1280×720
ex.warnings   # наложения, выход за край, мелкий кегль: пусто = чисто
```

## Параметры (из кода)

```
Этапы шевронами и строки под ними: что делаем, результат, кто участвует. Тон нарастает к последнему этапу.

phases: [{'title': 'Обследование', 'sub': '2 недели, октябрь'}] 2–6 штук.
rows: [{'label': 'Что делаем', 'cells': ['текст' или ['пункт', 'пункт'], ...]}] по ячейке на этап.
      Пункты списка понимают **жирный ключ**. Без label у всех строк колонка подписей не рисуется (схема «вход → как → результат»).
gates: [{'after': 0, 'label': 'Решение о запуске', 'items'?: [...]}] ворота-ромбы между этапами (after: индекс этапа, -1 = до первого).
decision_row: подпись строки, которая выделяется акцентом (например, «Решение на выходе»).
cell_role: кегль ячеек, 'small' или 'label' (крупнее, когда строк мало и на слайде есть место).
flat: плоские блоки без шевронов и крупные заголовки (для цепочки доводов «риски → полномочия → практика», где нет хода времени).
```

## Пример

`stages_rows` (кадр: `python3 tests/demo.py stages_rows`)

```python
def stages_rows():
    return X.stages([{'title': '1  Обследование', 'sub': '2 недели, октябрь'}, {'title': '2  Консалтинг', 'sub': '2 месяца, до декабря'}, {'title': '3  Стройка', 'sub': '2027 год'}],
                    rows=[{'label': 'Главный вопрос', 'cells': ['Как устроена компания и где данные', 'Сколько принесёт каждое направление', 'Что строим первым и сколько это даст']},
                          {'label': 'Что делаем', 'cells': [['Встречи с финансами и ИТ', 'Образцы выгрузок'], ['MVP юнит-экономики', 'Проверка B2B-продукта'], ['Хранилище', 'Пилот продукта']]},
                          {'label': 'Решение на выходе', 'cells': ['Запускаем ли консалтинг', 'Какие проекты в 2027', 'Что строим дальше']}],
                    decision_row='Решение на выходе')
```

`stages_gates` (кадр: `python3 tests/demo.py stages_gates`)

```python
def stages_gates():
    return X.stages([{'title': 'Идея'}, {'title': 'Расчёт'}, {'title': 'План и пилот'}, {'title': 'Внедрение'}, {'title': 'Закрытие'}],
                    gates=[{'after': 0, 'label': 'Идея обоснована', 'items': ['Финансовая цель', 'Владелец назначен']},
                           {'after': 1, 'label': 'Бизнес-план одобрен', 'items': ['Финансы подтвердили']},
                           {'after': 2, 'label': 'План внедрения одобрен', 'items': ['Вехи и результаты']},
                           {'after': 3, 'label': 'Внедрено', 'items': ['Вехи пройдены']},
                           {'after': 4, 'label': 'Эффект получен', 'items': ['Эффект в отчётности']}])
```

  смотреть: https://www.bcg.com/publications/2026/telecom-at-a-crossroads-a-blueprint-for-reinventing-telcos-in-the-middle-east
