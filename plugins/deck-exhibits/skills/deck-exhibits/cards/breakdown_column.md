# Столбец-разбивка с таблицей (`breakdown_column`)

> Собрано `build_docs.py` из `catalog.py` и кода функции. Руками не править.

**Что говорит слайд.** Из чего состоит одно большое число, с параметрами частей в таблице.

**Брать, когда в ТЗ:** «рынок состоит из», «объём рынка по сегментам с проникновением», «в десять раз больше проданного».

**Не брать, если:** несколько периодов (stacked_columns).

**Данные на вход:** [(часть, значение, колонки таблицы…)] сверху вниз; compare: малый столбец и кратность.

**Потолки:** частей до 14.

**Типы сообщения:** Структура целого.

## Правила оформления

- Тон от тёмного сверху к светлому вниз, таблица выровнена по частям.

## Вызов

```python
import sys; sys.path.insert(0, SKILL_DIR)   # SKILL_DIR: папка скилла, см. SKILL.md
import exhibits as X
ex = X.breakdown_column(segments, *, col_titles=(), total_label='', unit='', compare=None, decimals=0, height=420, theme=None, mode='показ', width=None)
ex.svg        # строка SVG, ширина 1168 px при 1:1 со слайдом 1280×720
ex.warnings   # наложения, выход за край, мелкий кегль: пусто = чисто
```

## Параметры (из кода)

```
Один высокий столбец, разбитый на части, и таблица частей справа. Для «рынок из чего состоит».

segments: [('Аутсорсинг', 450, '400–500', '5–10'), ...] сверху вниз: имя, значение для высоты, колонки таблицы.
compare: ('Продано сейчас', 145, '×10') маленький столбец слева со стрелкой-кратностью.
```

## Пример

`breakdown_column` (кадр: `python3 tests/demo.py breakdown_column`)

```python
def breakdown_column():
    segs = [('Защита данных', 75, '50–100', '30–35'), ('Риски и комплаенс', 75, '50–100', '30–35'), ('Облачная безопасность', 75, '50–100', '1–5'),
            ('Сетевая безопасность', 75, '50–100', '15–20'), ('Консалтинг', 150, '100–200', '15–20'), ('Безопасность приложений', 150, '100–200', '1–5'),
            ('Мониторинг и реагирование', 450, '400–500', '1–5'), ('Аутсорсинг', 450, '400–500', '5–10')]
    return X.breakdown_column(segs, col_titles=('Рынок, млрд $', 'Проникновение, %'), total_label='1,5–2,0 трлн $',
                              compare=('Продано', 145, '×10'))
```
