# Матрица 2×2 и карта позиционирования (`matrix_2x2`)

> Собрано `build_docs.py` из `catalog.py` и кода функции. Руками не править.

**Что говорит слайд.** Расстановка объектов по двум осям; тон клетки говорит о качестве зоны; облака групп.

**Брать, когда в ТЗ:** «приоритизация», «позиционирование», «зоны», «карта рынка»; у каждого объекта две независимые оценки (влияние и срок, глубина и устойчивость), сообщение про зоны или группы.

**Не брать, если:** оси не независимы; точек больше 25.

**Данные на вход:** points [{label, x, y}] в долях оси 0–1; quadrants; groups.

**Потолки:** точек до 25; групп-облаков до 5.

**Типы сообщения:** Расстановка по двум осям.

## Правила оформления

- Подписи точек сами ищут место без наложения.
- quadrants: тон клетки по смыслу (good, warn, bad), не украшение.
- groups рисуют облака и подписывают группу жирным.


## Параметры (из кода)

```
Расстановка по двум осям.

points: [{'label', 'x', 'y', 'cls'?, 'n'?}] x и y от 0 до 1 (доля оси) или в своих единицах при заданных scale.
quadrants: {'tl': ('Название', 'good'|'warn'|'bad'|'accent'|'grey'|'none'), 'tr':..., 'bl':..., 'br':...} тон клетки по смыслу зоны.
groups: {'Западная Европа': [метки точек]} облака групп с подписью жирным (карта позиционирования).
numbered: точки кружками с номером вместо подписей (для карты рисков; номер из 'n').
classes: {'cls': ('подпись в легенде', роль цвета)} цвет точки несёт один смысл.
ends: подписи концов оси X; y_ends: оси Y (по умолчанию как ends). Для «срок × влияние»: ends=('быстро', 'долго'), y_ends=('низко', 'высоко').
```

## Пример

`matrix_2x2` (кадр: `python3 tests/demo.py matrix_2x2`)

```python
def matrix_2x2():
    pts = [{'label': 'Потоковые данные', 'x': 0.68, 'y': 0.85}, {'label': 'Физические активы', 'x': 0.88, 'y': 0.9},
           {'label': 'Масштаб сети', 'x': 0.87, 'y': 0.72}, {'label': 'Интеграция систем', 'x': 0.68, 'y': 0.56},
           {'label': 'Капитал', 'x': 0.28, 'y': 0.57}, {'label': 'Численность', 'x': 0.25, 'y': 0.25},
           {'label': 'Экспертиза', 'x': 0.86, 'y': 0.36}, {'label': 'Операционная эффективность', 'x': 0.6, 'y': 0.22}]
    return X.matrix_2x2(pts, x_label='Глубина защиты от конкурентов', y_label='Устойчивость к ИИ',
                        quadrants={'tl': ('Устойчиво, но мелко', 'warn'), 'tr': ('Устойчиво и глубоко', 'good'),
                                   'bl': ('Хрупко и мелко', 'bad'), 'br': ('Хрупко, но глубоко', 'warn')})
```
