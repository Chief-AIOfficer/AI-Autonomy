# Карта сегментов (`segment_map`)

> Собрано `build_docs.py` из `catalog.py` и кода функции. Руками не править.

**Что говорит слайд.** Колонки-сегменты с метриками плашками и составом плитками.

**Брать, когда в ТЗ:** «вселенная продуктов», «сегменты рынка с размером и маржой», «из чего состоит каждый сегмент».

**Не брать, если:** сегментов больше 6.

**Данные на вход:** segments [{title, icon, metrics, items, hl}], metric_labels.

**Потолки:** сегментов 2–6.

**Типы сообщения:** Логика и состав, Структура целого.

## Правила оформления

- Выделенный сегмент тёмный, остальные светлее.

## Вызов

```python
import sys; sys.path.insert(0, SKILL_DIR)   # SKILL_DIR: папка скилла, см. SKILL.md
import exhibits as X
ex = X.segment_map(segments, *, metrics=(), metric_labels=(), label_w=150, row_label='Состав', theme=None, mode='показ', width=None)
ex.svg        # строка SVG, ширина 1168 px при 1:1 со слайдом 1280×720
ex.warnings   # наложения, выход за край, мелкий кегль: пусто = чисто
```

## Параметры (из кода)

```
Карта сегментов: колонки-сегменты, под шапкой строки метрик плашками, ниже плитки состава. «Вселенная» продуктов по группам.

segments: [{'title': 'Вычисления и чипы', 'icon'?: 'cpu', 'metrics': ['$40 | $70', '~20%'], 'items': ['Подложки', ...], 'hl'?: True}]
metric_labels: подписи строк метрик слева.
```

## Пример

`segment_map` (кадр: `python3 tests/demo.py segment_map`)

```python
def segment_map():
    return X.segment_map([{'title': 'Вычисления и чипы', 'icon': 'cpu', 'metrics': ['40 | 70', '~20%'], 'items': ['Подложки', 'Литография', 'Газы', 'Полировка'], 'hl': True},
                          {'title': 'Корпуса и платы', 'icon': 'circuit-board', 'metrics': ['30 | 50', '~15%'], 'items': ['Подложки корпусов', 'Герметики', 'Материалы плат']},
                          {'title': 'Тепло и питание', 'icon': 'thermometer', 'metrics': ['6 | 10', '~25%'], 'items': ['Термоинтерфейсы', 'Теплоотводы']},
                          {'title': 'Оптика', 'icon': 'aperture', 'metrics': ['3 | 5', '~15%'], 'items': ['Дисплейные материалы', 'Клеи']}],
                         metric_labels=['Рынок, млрд $ 2025 | 2030', 'Маржа EBITDA'])
```
