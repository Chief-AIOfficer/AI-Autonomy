# Цитаты (`quotes`)

> Собрано `build_docs.py` из `catalog.py` и кода функции. Руками не править.

**Что говорит слайд.** Голос клиента: 2–4 цитаты и вывод из них.

**Брать, когда в ТЗ:** «клиенты говорят», «из интервью», «голос клиента».

**Не брать, если:** цитат больше 4 (приложение).

**Данные на вход:** [(цитата, автор должностью)], lead.

**Потолки:** цитат 2–4; цитата до 8 строк.

**Типы сообщения:** Голос клиента.

## Правила оформления

- Автор должностью и отраслью, без имён, если клиент не разрешил.
- Источник слов клиента сноской на слайде, не «по вашим словам».

## Вызов

```python
import sys; sys.path.insert(0, SKILL_DIR)   # SKILL_DIR: папка скилла, см. SKILL.md
import exhibits as X
ex = X.quotes(items, *, lead=None, theme=None, mode='показ', width=None)
ex.svg        # строка SVG, ширина 1168 px при 1:1 со слайдом 1280×720
ex.warnings   # наложения, выход за край, мелкий кегль: пусто = чисто
```

## Параметры (из кода)

```
Голос клиента: цитаты в карточках одного размера, крупная кавычка, автор должностью; вывод слева на тёмной колонке.

items: [('Нам нужно право на ремонт…', 'Руководитель сервиса, ритейл')], 2–4 цитаты.
lead: вывод из цитат для левой колонки.
```

## Пример

`quotes` (кадр: `python3 tests/demo.py quotes`)

```python
def quotes():
    return X.quotes([('Продукт должен быть ремонтопригодным: меньше клея, больше винтов', 'Покупатель, 34 года'),
                     ('Запчасти нужны и через 10–15 лет после выпуска модели', 'Покупательница, 52 года'),
                     ('Ремонт не обязан быть бесплатным, но должен быть возможен', 'Покупатель, 41 год')],
                    lead='Клиенты ждут действий прежде всего от производителей')
```
