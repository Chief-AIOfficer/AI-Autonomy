# Полоса долей (`share_bar`)

> Собрано `build_docs.py` из `catalog.py` и кода функции. Руками не править.

**Что говорит слайд.** Как делится целое на 2–4 части, и что значит каждая.

**Брать, когда в ТЗ:** «делятся на три группы», «горизонты», «доля компаний на каждом уровне».

**Не брать, если:** частей больше 4 (stacked_100 или bar_ranked); сравнение нескольких целых (stacked_100).

**Данные на вход:** [(имя части, доля, описание)].

**Потолки:** частей 2–4.

**Типы сообщения:** Структура целого.

## Правила оформления

- Описание под каждой частью вместо легенды.

## Вызов

```python
import sys; sys.path.insert(0, SKILL_DIR)   # SKILL_DIR: папка скилла, см. SKILL.md
import exhibits as X
ex = X.share_bar(parts, *, decimals=0, highlight=None, theme=None, mode='показ', width=None)
ex.svg        # строка SVG, ширина 1168 px при 1:1 со слайдом 1280×720
ex.warnings   # наложения, выход за край, мелкий кегль: пусто = чисто
```

## Параметры (из кода)

```
Одна полоса 100% и описание под каждой частью. Для «организации делятся на три горизонта».

parts: [('Горизонт 1: доступ', 46, 'Сотрудникам дают общие ИИ-инструменты'), ...] 2–4 части.
```

## Пример

`share_bar` (кадр: `python3 tests/demo.py share_bar`)

```python
def share_bar():
    return X.share_bar([('Горизонт 1: доступ', 46, 'Сотрудникам дают общие ИИ-инструменты для текущей работы'),
                        ('Горизонт 2: автоматизация', 43, 'ИИ автоматизирует и улучшает существующие процессы'),
                        ('Горизонт 3: перестройка', 11, 'Работу и источники ценности перестраивают вокруг ИИ')], highlight='Горизонт 3: перестройка')
```
