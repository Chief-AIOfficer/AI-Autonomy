# Разрыв до цели (`gap_to_target`)

> Собрано `build_docs.py` из `catalog.py` и кода функции. Руками не править.

**Что говорит слайд.** Сколько не хватает до цели по каждому объекту.

**Брать, когда в ТЗ:** «цель», «план», «амбиция», «не хватает», «отставание от плана».

**Не брать, если:** цели нет (bar_ranked); динамика к цели во времени (lines с целевой линией).

**Данные на вход:** [(подпись, факт, цель)].

**Потолки:** строк до 10.

**Типы сообщения:** Разница и мост.

## Правила оформления

- Факт серой полосой, разрыв стрелкой акцента, цель тёмной плашкой.
- Перевыполнение показывается зелёной плашкой «выше цели».

## Вызов

```python
import sys; sys.path.insert(0, SKILL_DIR)   # SKILL_DIR: папка скилла, см. SKILL.md
import exhibits as X
ex = X.gap_to_target(rows, *, unit='', decimals=0, target_word='цель', fact_word='сейчас', theme=None, mode='показ', width=None)
ex.svg        # строка SVG, ширина 1168 px при 1:1 со слайдом 1280×720
ex.warnings   # наложения, выход за край, мелкий кегль: пусто = чисто
```

## Параметры (из кода)

```
Сколько не хватает до цели: полоса факта, стрелка разрыва, плашка цели. По строке на объект.

rows: [('Москва', 40, 54), ...]: подпись, факт, цель.
```

## Пример

`gap_to_target` (кадр: `python3 tests/demo.py gap_to_target`)

```python
def gap_to_target():
    return X.gap_to_target([('Все регионы', 40, 54), ('Центр', 66, 70), ('Сибирь', 14, 34), ('Урал', 54, 61), ('Юг', 19, 39)],
                           unit='%', target_word='цель 2030')
```
