# Веер и сборка (`fan`)

> Собрано `build_docs.py` из `catalog.py` и кода функции. Руками не править.

**Что говорит слайд.** Из одного запроса расходятся параллельные направления, каждое копает своё, и сходятся в один итог; решающие подсвечены.

**Брать, когда в ТЗ:** «по агенту на линию», «расходится на N направлений», «параллельно», «сводим в один отчёт», разведка, ресёрч, сбор из источников.

**Не брать, если:** у направлений есть порядок и важен ход (stages); итога нет и направления просто перечисляются (points, pillars); нужен вход и выход по каждому направлению (table).

**Данные на вход:** source {title, sub?, icon?}; items [{title, text, icon?, hi?}]; target {title, sub?, icon?}.

**Потолки:** направлений 3–10; название и описание направления по одной строке.

**Типы сообщения:** Процесс и этапы, Логика и состав.

## Правила оформления

- Решающие направления (hi) залиты акцентом, их связи толще и тоже акцентом; остальные серые.
- Связи под прямым углом через общую шину слева и справа, косых линий нет.
- Подпись «Линия 1», «Направление 2» не ставить: веер и так показывает, что их несколько (замечание 11.10).

## Вызов

```python
import sys; sys.path.insert(0, SKILL_DIR)   # SKILL_DIR: папка скилла, см. SKILL.md
import exhibits as X
ex = X.fan(source, items, target, *, theme=None, mode='показ', width=None)
ex.svg        # строка SVG, ширина 1168 px при 1:1 со слайдом 1280×720
ex.warnings   # наложения, выход за край, мелкий кегль: пусто = чисто
```

## Параметры (из кода)

```
Веер и сборка: из одного запроса расходятся параллельные направления, каждое копает своё, и сходятся в один итог.

source, target: {'title': 'Запрос', 'sub'?: 'паспорт вакансии', 'icon'?: 'search'}.
items: [{'title': 'Люди', 'text': 'заказчик роли, руководитель', 'icon'?: 'users', 'hi'?: True}] 3–10 штук.
hi: решающие направления, полоса и её связи акцентом. Остальные серые.
Название и описание направления в одну строку каждое: длинное падает FitError, текст сокращать.
Связи ортогональные, общая шина слева и справа (правило стиля v3).
```

## Пример

`fan_research` (кадр: `python3 tests/demo.py fan_research`)

```python
def fan_research():
    return X.fan({'title': 'Вопрос', 'sub': 'стоит ли выходить в новый регион', 'icon': 'search'},
                 [{'icon': 'users', 'title': 'Спрос', 'text': 'кто купит и сколько готов платить'},
                  {'icon': 'building-2', 'title': 'Конкуренты', 'text': 'кто уже там и на чём держится', 'hi': True},
                  {'icon': 'scale', 'title': 'Регуляторика', 'text': 'лицензии, сроки, ограничения', 'hi': True},
                  {'icon': 'truck', 'title': 'Логистика', 'text': 'склады, плечо доставки, стоимость'},
                  {'icon': 'wallet', 'title': 'Экономика', 'text': 'вложения, окупаемость, риск'}],
                 {'title': 'Отчёт', 'sub': 'вывод, условия входа, риски', 'icon': 'file-check'})
```
