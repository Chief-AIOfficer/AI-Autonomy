# Линии (`lines`)

> Собрано `build_docs.py` из `catalog.py` и кода функции. Руками не править.

**Что говорит слайд.** Как менялось во времени; одна-две главные линии, остальные фоном.

**Брать, когда в ТЗ:** «динамика», «тренд», больше 12 точек или 3+ серии, «после события», перелом, «план и факт по месяцам».

**Не брать, если:** точек меньше 4 (columns); сравнение категорий без времени (bar_ranked).

**Данные на вход:** подписи оси X + {серия: значения}; больше 4 серий только с highlight или table.

**Потолки:** акцентных серий 1–2; событий до 3; полос периодов до 6.

**Типы сообщения:** Динамика.

## Правила оформления

- Подпись имени и последнего значения у конца линии, легенды нет.
- events: вертикальные пунктиры с подписью; bands: светлые полосы эпох.
- gap_fill: заливка между фактом и планом с подписью разрыва.
- Много серий: table справа (значение сейчас и среднее), а не подписи у линий.
- Малые кратные: несколько lines одинаковой ширины через hstack.

## Вызов

```python
import sys; sys.path.insert(0, SKILL_DIR)   # SKILL_DIR: папка скилла, см. SKILL.md
import exhibits as X
ex = X.lines(x, series, *, highlight=None, unit='', decimals=0, events=None, bands=None, gap_fill=None, table=None, y_from_zero=None, height=340, end_labels=True, title=None, sub=None, top_min=None, theme=None, mode='показ', width=None)
ex.svg        # строка SVG, ширина 1168 px при 1:1 со слайдом 1280×720
ex.warnings   # наложения, выход за край, мелкий кегль: пусто = чисто
```

## Параметры (из кода)

```
Линии по времени. Главная серия акцентом, остальные серым; подпись имени и последнего значения у конца линии.

x: подписи точек по оси (годы, месяцы); прореживаются автоматически.
series: {имя: [значения или None]}; больше 4 серий: только с table или с highlight одной-двух.
highlight: имена серий акцентом (первая accent, вторая accent_dark); без него при одной серии она акцентная.
events: [(индекс, 'Начало пандемии')] вертикальные пунктиры с подписью сверху.
bands: [(i0, i1, 'подпись')] светлые полосы периодов (эпохи, сроки руководителей).
gap_fill: ('Факт', 'План', '1 026 FTE сверх плана') заливка между двумя сериями там, где первая выше.
table: {'cols': ['2025', 'среднее'], 'values': {имя: [..]}, 'decimals': 1} легенда-таблица справа вместо подписей у линий.
title, sub: заголовок панели и единицы под ним (для малых кратных).
```

`lines_table` (кадр: `python3 tests/demo.py lines_table`)

```python
def lines_table():
    yrs = [str(y) for y in range(2015, 2026)]
    import random
    random.seed(3)
    ser = {}
    for k in ['Акции', 'Госдолг', 'Депозиты', 'Корп. долг', 'Недвижимость', 'Активы', 'Долг домохозяйств']:
        v, out = 100, []
        for _ in yrs:
            v += random.uniform(-6, 10)
            out.append(round(v, 1))
        ser[k] = out
    tab = {'cols': ['2025', 'среднее'], 'values': {k: [round(ser[k][-1] / 60, 1), round(sum(ser[k]) / len(ser[k]) / 60, 1)] for k in ser}}
    return X.lines(yrs, ser, highlight=['Акции'], table=tab, sub='индекс, 2015 = 100')
```

## Образцы (публичные слайды, описаны словами)

- `C_trend_02` McKinsey 2026: Два линейных графика, подписано последнее значение. Одна синяя линия на график, один кружок на последней точке и одна подпись, серая сетка. Заголовок это вывод, подзаголовок название показателя.
  смотреть: https://www.mckinsey.com/industries/financial-services/our-insights/global-banking-annual-review
- `C_trend_03` McKinsey 2026: Линии с легендой-таблицей. Семь линий, но значения 2025 и среднее за период вынесены в таблицу, совмещённую с легендой, так что подписи на графике не нужны. Антипример наполовину: много линий, читается за счёт таблицы.
  смотреть: https://www.mckinsey.com/mgi/our-research/the-global-balance-sheet-2026-imbalance-and-divergence
- `D_trend_02` Datawrapper 2026: Тот же график с цветными полосами периодов. Фон разбит светлыми полосами по периодам, ключевые пики подписаны снизу, средняя линия выделена цветом. Приём для рядов, где важен контекст эпох.
  смотреть: https://www.datawrapper.de/blog/fix-my-chart-approval-ratings
- `D_trend_05` ONS 2022: Линия с вертикальными метками событий и значением в конце. Две пунктирные вертикали с короткими подписями событий, последнее значение выделено цветом справа, подписи осей минимальны. Заголовок говорит вывод.
  смотреть: https://service-manual.ons.gov.uk/data-visualisation/guidance/annotations
- `D_before_after_01` Storytelling with Data 2024: Было-стало: график с таблицей и вывод со словами. Слева все серии и таблица на одном графике, справа два простых графика, заголовок-вывод, два текстовых блока и призыв к действию внизу. Главное выделено оранжевым и чёрным, остальное серое.
  смотреть: https://www.storytellingwithdata.com/blog/dont-hide-the-crucial-findings
- `D_before_after_07` Storytelling with Data 2024: Было-стало: перегруженная таблица-график и слайд с двумя блоками. Слева стопки и овалы с цифрами повсюду, справа слайд с заголовком-выводом, двумя колонками (график слева, рекомендация под каждым), цветом выделены регионы. Склейка из двух картинок поста.
  смотреть: https://www.storytellingwithdata.com/blog/a-diverging-bar-makeover-how-to-tackle-the-challenge-of-scope-creep
- `B2_compare_03` Bain 2023: Три малых кратных столбца: красный против серого. три региона на одной шкале, красные столбцы показывают фонды, серые индекс. Подписи регионов над графиками.
  смотреть: https://www.bain.com/globalassets/about/2023-global-pe-report---roadshow-deck.pdf
