# Доли карточками (`share_cards`)

> Собрано `build_docs.py` из `catalog.py` и кода функции. Руками не править.

**Что говорит слайд.** Как распределить усилия или бюджет: 2–3 доли вокруг кольца, у каждой суть.

**Брать, когда в ТЗ:** «правило 70/20/10», «распределение усилий», «основное внимание на людей».

**Не брать, если:** долей больше 3 (share_bar).

**Данные на вход:** [(доля, заголовок, [пункты])], center: вопрос в кольце.

**Потолки:** долей 2–3.

**Типы сообщения:** Главная мысль, Структура целого.

## Правила оформления

- Самая большая доля в самой большой карточке, цвет доли совпадает с сегментом кольца.

## Вызов

```python
import sys; sys.path.insert(0, SKILL_DIR)   # SKILL_DIR: папка скилла, см. SKILL.md
import exhibits as X
ex = X.share_cards(parts, *, center='', theme=None, mode='показ', width=None)
ex.svg        # строка SVG, ширина 1168 px при 1:1 со слайдом 1280×720
ex.warnings   # наложения, выход за край, мелкий кегль: пусто = чисто
```

## Параметры (из кода)

```
Доли усилий или бюджета карточками вокруг кольца: 70/20/10. Самая большая доля в самой большой карточке.

parts: [(70, 'Люди и процессы', ['Вовлечь руководителей', ...]), (20, 'Данные и технологии', [...]), (10, 'ИИ', [...])]
```

## Пример

`share_cards` (кадр: `python3 tests/demo.py share_cards`)

```python
def share_cards():
    return X.share_cards([(70, 'Люди и процессы', ['Вовлечь руководителей ясной целью', 'Вовлечь сервисные команды в создание', 'Перестроить процессы и роли']),
                          (10, 'ИИ', ['Модели под задачи сервиса']), (20, 'Данные и технологии', ['Довести технологии до поля', 'Связать системы сквозной автоматизацией'])],
                         center='Как распределить усилия в ИИ-трансформации сервиса')
```
