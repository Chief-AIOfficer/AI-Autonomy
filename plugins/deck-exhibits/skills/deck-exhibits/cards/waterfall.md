# Мост изменений (`waterfall`)

> Собрано `build_docs.py` из `catalog.py` и кода функции. Руками не править.

**Что говорит слайд.** Из чего сложилась разница между двумя числами.

**Брать, когда в ТЗ:** «за счёт», «вклад факторов», «от … к …», «что съело маржу», два итога и шаги между ними.

**Не брать, если:** шагов больше 8 (объедини в «прочее»); нет общей единицы у шагов.

**Данные на вход:** старт (подпись, число), шаги [(подпись, ±число)], конец; промежуточный итог шагом (подпись, None).

**Потолки:** шагов 1–8; выносок под шагами до 2.

**Типы сообщения:** Разница и мост.

## Правила оформления

- Мост обязан сходиться: функция проверяет сумму.
- Без highlight рост акцентом, падение красным; с highlight акцент только на шагах из заголовка.
- Когда шаги меньше половины базы, ось обрезается автоматически, со знаком разрыва на итогах.
- Справа от моста можно поставить таблицу через hstack.

## Вызов

```python
import sys; sys.path.insert(0, SKILL_DIR)   # SKILL_DIR: папка скилла, см. SKILL.md
import exhibits as X
ex = X.waterfall(start, steps, end=None, *, unit='', decimals=0, highlight=(), notes=None, height=330, axis='auto', theme=None, mode='показ', width=None)
ex.svg        # строка SVG, ширина 1168 px при 1:1 со слайдом 1280×720
ex.warnings   # наложения, выход за край, мелкий кегль: пусто = чисто
```

## Параметры (из кода)

```
Мост: из чего сложилась разница между двумя числами.

start: ('Маржа 2025', 18.4); steps: [('Цены', +2.1), ('Объём', +1.3), ('Себестоимость', -0.9)];
end: ('Маржа 2026', 20.9) или None (посчитается). Шаг ('Итог 1П', None) рисует промежуточный итог.
highlight: шаги, о которых заголовок; остальные приращения серые. Без highlight рост accent, падение bad.
notes: {шаг: текст} выноска под крупнейшими шагами (не больше двух).
axis: 'auto' обрезает ось со знаком разрыва, если размах шагов меньше половины базы; 'zero' всегда от нуля.
```

## Пример

`waterfall` (кадр: `python3 tests/demo.py waterfall`)

```python
def waterfall():
    return X.waterfall(('Маржа 2025', 18.4), [('Цены', 2.1), ('Объём', 1.3), ('Себестоимость', -0.9), ('Курс', -0.3), ('Прочее', 0.3)],
                       ('Маржа 2026', 20.9), unit='п.п.', decimals=1, highlight=['Цены'],
                       notes={'Цены': 'Повышение тарифов с марта дало две трети роста'})
```
