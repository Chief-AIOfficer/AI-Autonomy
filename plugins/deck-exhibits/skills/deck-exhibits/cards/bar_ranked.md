# Рейтинг полосами (`bar_ranked`)

> Собрано `build_docs.py` из `catalog.py` и кода функции. Руками не править.

**Что говорит слайд.** Кто больше: 4–20 объектов в один момент, мы среди них.

**Брать, когда в ТЗ:** «лидер», «на каком месте», «больше всех», «в сравнении с», сравнение с ориентирами.

**Не брать, если:** важна динамика (lines, columns); есть отрицательные (pair_delta, waterfall); меньше 4 объектов (pair_delta); объекты делятся на 2–3 лагеря с выводом по каждому (columns с groups, до 20 столбцов).

**Данные на вход:** [(подпись, число ≥ 0)]; по желанию колонка изменения справа, строка итога, диапазон до значения.

**Потолки:** до 20 строк; выносок 1–2; акцент на 1–3 строки.

**Типы сообщения:** Сравнение и рейтинг.

## Правила оформления

- Сортировка по убыванию, если порядок не задан смыслом.
- Красим акцентом только тех, о ком заголовок; остальные серые.
- Значение у конца полосы, оси нет.
- Колонка «изменение» справа вместо второго графика.

## Вызов

```python
import sys; sys.path.insert(0, SKILL_DIR)   # SKILL_DIR: папка скилла, см. SKILL.md
import exhibits as X
ex = X.bar_ranked(data, *, highlight=(), unit='', decimals=0, sort=True, value_inside=False, total=None, cols=(), notes=None, scale_max=None, label_w=None, theme=None, mode='показ', width=None)
ex.svg        # строка SVG, ширина 1168 px при 1:1 со слайдом 1280×720
ex.warnings   # наложения, выход за край, мелкий кегль: пусто = чисто
```

## Параметры (из кода)

```
Рейтинг горизонтальными полосами: кто больше. Акцент только на тех, о ком заголовок.

data: [(подпись, значение)] или [{'label', 'value', 'sub'?, 'to'?}]; 'to' рисует диапазон штриховкой до этого значения.
highlight: подписи строк, которые красить акцентом; остальные серые.
total: {'label', 'value'} строка итога под чертой, жирная.
cols: правые колонки [{'title', 'values': [...], 'decimals'?, 'sign'?}] (например, «изменение, %»).
notes: {подпись: текст} выноска справа от полосы.
```

## Пример

`bar_ranked` (кадр: `python3 tests/demo.py bar_ranked`)

```python
def bar_ranked():
    return X.bar_ranked(
        [('Сбер', 18.6), ('ВТБ', 16.9), ('Наш банк', 16.7), ('Альфа-Банк', 16.4), ('Т-Банк', 13.1), ('Газпромбанк', 12.1),
         ('Райффайзен', 9.7), ('Совкомбанк', 7.5)],
        highlight=['Наш банк'], unit='млрд ₽', decimals=1,
        cols=[{'title': 'к 2025, %', 'values': [4.1, 2.0, 11.3, -0.4, 3.3, 1.2, -6.0, 0.8], 'sign': True}],
        total={'label': 'Рынок, медиана', 'value': 14.6}, notes={'Наш банк': 'рост вдвое быстрее рынка за счёт МСБ'})
```

## Образцы (публичные слайды, описаны словами)

- `D_compare_01` Datawrapper 2026: Рейтинг с выделенной красным серией. Все полосы серые, а интересующие красные: сравнение инвестиций с известными ориентирами. Подписи в строках, штриховка показывает диапазон.
  смотреть: https://www.datawrapper.de/blog/ai-investments-2026-vs-alternative-ways-to-spend-money
- `C_compare_05` McKinsey 2026: Рейтинг столбцами и «леденцы» с отметками. Слева столбцы (доллары плюс поправка), справа точки на шкале кратности ВВП с ромбом среднего и кружком пика. Итог «Global» отделён линией и выделен жирным.
  смотреть: https://www.mckinsey.com/mgi/our-research/the-global-balance-sheet-2026-imbalance-and-divergence

## Антипримеры («Не то»)

- `B2_compare_04` Oliver Wyman 2023: Полосы по странам, значение рядом, ключевые выделены рамкой. три страны в столбцах, под флагом полосы и проценты, жёлтая рамка отмечает ячейки, о которых говорит заголовок. Тёмно-зелёная колонка слева даёт заголовок и фон.
  смотреть: https://www.oliverwyman.de/content/dam/oliver-wyman/v2-de/publications/2023/OW-gfu-Going-full-circle-report-vF4.pdf
