# Резюме (`exec_summary`)

> Собрано `build_docs.py` из `catalog.py` и кода функции. Руками не править.

**Что говорит слайд.** Итог для руководителя текстом: ситуация, сложность, решение; или пирамида «вывод, доводы, как пришли».

**Брать, когда в ТЗ:** «резюме», «executive summary», «главное на одном слайде», начало или конец деки.

**Не брать, если:** выводы параллельны и равны (points).

**Данные на вход:** blocks [{label, lead с **ключом**, bullets?, hl?}].

**Потолки:** блоков 2–5; пунктов в блоке до 4.

**Типы сообщения:** Резюме.

## Правила оформления

- Ведущая фраза блока с жирным ключом, цифры в тексте.
- Блок-решение выделяется рамкой (hl).
- style="pyramid": вывод первым, ярусы подписаны скобками справа.

## Вызов

```python
import sys; sys.path.insert(0, SKILL_DIR)   # SKILL_DIR: папка скилла, см. SKILL.md
import exhibits as X
ex = X.exec_summary(blocks, *, style='labels', theme=None, mode='показ', width=None)
ex.svg        # строка SVG, ширина 1168 px при 1:1 со слайдом 1280×720
ex.warnings   # наложения, выход за край, мелкий кегль: пусто = чисто
```

## Параметры (из кода)

```
Резюме для руководителя: блоки с метками слева (Ситуация, Сложность, Решение) или скобки-ярусы пирамиды справа.

blocks: [{'label': 'Ситуация', 'lead': '**Маржа падает** третий год…', 'bullets'?: ['…', '…'], 'hl'?: True, 'aside'?: 'слайды 3–4'}]
aside: короткая пометка в отдельной колонке справа (где это раскрыто, на каких слайдах).
style: 'labels' метки слева и черта; 'pyramid' вывод первым, ярусы подписаны справа скобками.
hl: блок-решение, выделяется тонкой рамкой акцента.
```

## Пример

`exec_summary` (кадр: `python3 tests/demo.py exec_summary`)

```python
def exec_summary():
    return X.exec_summary([{'label': 'Ситуация', 'lead': '**Маржа продуктового ритейла 7,1%** против 22,9% у остальной розницы, за пять лет минус 0,6 п.п.',
                            'bullets': ['Дискаунтеры за то же время **прибавили 0,2 п.п.**', 'Инфляция съела объёмы: **минус 4,5%** в натуральном выражении']},
                           {'label': 'Сложность', 'lead': '**Ещё 0,2–2,7 п.п.** под угрозой в ближайшие пять лет, если ничего не менять',
                            'bullets': ['Обычных мер хватит только на **1–1,5 п.п.**']},
                           {'label': 'Решение', 'lead': '**Нужен шаг вверх по всем рычагам**: рост, эффективность, трансформация', 'hl': True,
                            'bullets': ['**Отстроиться** свежими продуктами и своей маркой', '**Снизить затраты** от поставщика до полки', '**Монетизировать** рекламу в магазинах']}])
```

`exec_pyramid` (кадр: `python3 tests/demo.py exec_pyramid`)

```python
def exec_pyramid():
    return X.exec_summary([{'label': 'Вывод', 'lead': '**Рекомендуем сместить продукт на покупателя**, а не на пользователя'},
                           {'label': 'Доводы', 'lead': 'Главные находки:', 'bullets': ['Покупателям **не хватает отчётов** об использовании', 'Пользователи **довольны** набором функций', 'Продажи **теряют крупные сделки** из-за пробелов']},
                           {'label': 'Как пришли', 'lead': 'Поговорили с **10 покупателями и 20 пользователями**', 'bullets': ['NPS покупателей **5,4 против 7,9** у пользователей']}], style='pyramid')
```

## Образцы (публичные слайды, описаны словами)

- `A_summary_03` McKinsey 2024: Резюме на тёмном фоне: назад, вперёд, решение. три блока с курсивными метками «Looking back / Outlook / Solution», цифры в тексте. Тёмный фон вместо белого, но плотность текста та же. Метки SCR слева от Slideworks.
  смотреть: https://slideworks.io/resources/how-to-write-executive-summary
- `B_summary_02` LEK 2021: Резюме для руководителя: шесть абзацев с жирными ключами. Только текст, но жирные ключевые слова позволяют читать по диагонали; один слайд, абзацы одинакового устройства.
  смотреть: https://assets.ctfassets.net/xpbu77rkft4z/5N50kXGA79nTkH40MUPQDc/da6f22d8cc22659d19c50d993e00d9ad/lek_process_automation.december_2021.pdf#page=3
- `D_summary_01` Untools 2024: Письмо по пирамиде Минто: вывод, аргументы, детали. Три яруса сверху вниз с подписями сбоку: рекомендация первой строкой, затем три довода, потом то, как к ним пришли. Подходит для слайда-резюме для руководителя.
  смотреть: https://untools.co/minto-pyramid/

## Антипримеры («Не то»)

- `A_summary_06` StrategyU 2025: Макет: резюме в три колонки. ситуация, находки, рекомендации тремя колонками под тёмными шапками, в рекомендациях нумерованные действия с цифрами.
  смотреть: https://strategyu.co/slide-layouts/
- `B2_summary_01` McKinsey 2025: Резюме: шесть тезисов с цифрами. шесть абзацев с одинаковым устройством, цифры в тексте, никаких картинок. Читается как список выводов по порядку, засечный заголовок.
  смотреть: https://iacpm.org/wp-content/uploads/2025/03/IACPM-McKinsey-Gen-AI-Webinar-2025.pdf
