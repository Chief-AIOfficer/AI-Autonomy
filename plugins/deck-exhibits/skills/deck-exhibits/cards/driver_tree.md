# Дерево драйверов (`driver_tree`)

> Собрано `build_docs.py` из `catalog.py` и кода функции. Руками не править.

**Что говорит слайд.** Из чего складывается показатель: корень слева, операторы на стыках, единицы в скобках.

**Брать, когда в ТЗ:** «модель рынка», «от чего зависит выручка», «дерево метрики», «снизу вверх».

**Не брать, если:** глубина больше 4 или дерево не влезает по высоте даже с подписями в одну строку (разбить на два).

**Данные на вход:** дерево {label, op, children, kind}.

**Потолки:** глубина до 4; листьев сколько влезет по высоте (FitError подскажет), при 16+ подписи в одну строку.

**Типы сообщения:** Логика и состав.

## Правила оформления

- Допущения светлее расчётных величин (kind="assume"), легенда внизу.

## Вызов

```python
import sys; sys.path.insert(0, SKILL_DIR)   # SKILL_DIR: папка скилла, см. SKILL.md
import exhibits as X
ex = X.driver_tree(tree, *, classes=None, row_h=None, widths=None, max_h=470, legend=True, dashed_label='гипотеза, цифры нет', theme=None, mode='показ', width=None)
ex.svg        # строка SVG, ширина 1168 px при 1:1 со слайдом 1280×720
ex.warnings   # наложения, выход за край, мелкий кегль: пусто = чисто
```

## Параметры (из кода)

```
Дерево драйверов слева направо: корень, ветки, оператор на стыке (× + −), единицы в скобках.

tree: {'label': 'Выручка [млн ₽]', 'op': '×', 'children': [...]} или 'ops': ['×', '−'] между соседними ветками;
      у узла 'cls' (класс из classes: цвет несёт владельца или вид), 'dashed': True (пунктирная рамка),
      'kind': 'assume' (лист-допущение светлее). В подписи допустим **жирный** (метка ML и т. п.).
classes: {'core': ('ядро', 'accent_pale'), 'com': ('коммерция', 'cat_3')} легенда классов в пустом углу под корнем.
dashed_label: подпись пунктира в легенде (что значит пунктирная рамка).
row_h: высота листа; по умолчанию 52 при малом дереве и компактно при большом.
widths: ширины колонок по уровням, последняя колонка (листья) получает остаток.
Глубина до 4. Число листьев не ограничено числом: дерево проверяется по высоте (max_h), не влезло: FitError с подсказкой разбить.
```

## Пример

`driver_tree` (кадр: `python3 tests/demo.py driver_tree`)

```python
def driver_tree():
    return X.driver_tree({'label': 'Выручка [млн ₽]', 'op': '×', 'children': [
        {'label': 'Клиенты [тыс.]', 'op': '×', 'children': [{'label': 'Охват рынка [тыс.]'}, {'label': 'Доля проникновения [%]', 'kind': 'assume'}]},
        {'label': 'Выручка на клиента [тыс. ₽]', 'op': '×', 'children': [{'label': 'Покупок в год [шт.]'}, {'label': 'Средний чек [тыс. ₽]', 'op': '+', 'children': [
            {'label': 'Базовый продукт [тыс. ₽]'}, {'label': 'Допродажи [тыс. ₽]', 'kind': 'assume'}]}]}]})
```
