# Шаблон профиля для deck-exhibits

Профиль добавляет к универсальному скиллу то, что знаете только вы: свою тему и шрифт, кто принимает выбор экспоната, чем вы собираете деки, какие приёмы вы уже отклонили. Без профиля скилл работает на штатном: тема v3 (Golos Text, синий акцент), рамка `frame/deck.py`, строка «Экспонат» показывается вам до вёрстки.

Куда положить (скилл берёт первый найденный):

1. `.agents/deck-exhibits/profile.md` в корне проекта (только для него, Codex и Claude Code);
2. `~/.agents/deck-exhibits/profile.md` (для всех проектов);
3. `.claude/deck-exhibits/profile.md` в корне проекта;
4. `~/.claude/deck-exhibits/profile.md`.

Профиль может быть одним файлом или папкой: `profile.md` как точка входа и рядом файлы по смыслу (например, `стиль.md`, `правила_по_клиентам.md`, `образцы/`, `тесты/`). Тогда в `profile.md` таблица «файл, что в нём, когда читать»: скилл читает соседние файлы только по ней.

Профиль личный: в публичный репозиторий и плагины его не кладут. Пустые разделы можно удалить.

```markdown
# Профиль deck-exhibits: <имя>

## Файлы профиля и когда их читать (если профиль папкой)
| Файл | Что в нём | Когда читать |
|---|---|---|
| стиль.md | <тема, шрифт, правила оформления> | <перед первым слайдом> |

## Кто принимает
Кто смотрит строку «Экспонат: …, почему: …» до вёрстки: <я / руководитель / заказчик>.
Новый тип слайда: <показать 2–3 варианта мне / решать самому>.

## Тема и шрифт
Своя тема: <полный путь к .toml или «штатная v3»>.
Шрифт компании: <полный путь к TTF или «Golos Text»>.
Режим по умолчанию: <показ / чтение>.

## Сборка деки
Чем собираю: <рамка скилла frame/deck.py / своя сборка: полный путь к модулю>.
Где лежат деки: <папка>. Кадры смотреть: <всегда / только перед отдачей>.

## Соседние скиллы
Дисциплина деки и сторилайна: <имя скилла или «нет»>.
Вычитка текстов подписей: <имя скилла или «нет»>.

## Мои правила сверх общих
Что я уже отклонил и почему, по пункту на строку. Например: «круговые диаграммы не брать», «шары Харви только для степени».
Свод замечаний к декам: <полный путь или «нет»>.

## Мои образцы
Папка своих отобранных слайдов: <полный путь или «нет»>.
```
