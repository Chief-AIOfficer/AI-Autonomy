# brainstorm-critic

Мозговой штурм, который заканчивается выбором, а не списком. Скилл сначала смотрит в ваших файлах, что уже решено и отвергнуто, потом разводит варианты четырьмя углами, сводит их по критериям, записанным до отбора, отдаёт отдельному агенту-критику и называет одну рекомендацию и ближайший шаг.

## Установка

```
/plugin marketplace add Chief-AIOfficer/AI-Autonomy
/plugin install brainstorm-critic@ai-autonomy
```

## Как вызвать

Словами: «давай поштурмим …», «покидай варианты …», «разнеси мою идею …», «какие роли мне подходят», «А или Б?». Или командой `/brainstorm-critic:brainstorm-critic <тема> [режим]`.

Режимы: быстрый, полный, без критика, критик, пре-мортем, развилка. Не назвали режим: скилл выберет сам и скажет какой.

## Что нужно заранее

Ничего обязательного. Скилл работает лучше, если в папке, из которой вы запускаете Claude Code, лежат ваши материалы по теме: профиль, прошлые решения, заметки. Он найдёт их сам на шаге 0.

## Личный профиль

Универсальный скилл можно дополнить своим профилем: где лежат ваши заметки и прошлые ресёрчи, какие реестры решений вы ведёте, какими агентами ищете и проверяете факты, как для вас читается угол «своё ремесло», ваши наблюдения. Шаблон: [reference/profile-template.md](reference/profile-template.md). Положите заполненный файл в `~/.claude/brainstorm-critic/profile.md` (для всех проектов) или в `.claude/brainstorm-critic/profile.md` в корне проекта. Для Codex те же пути с `.agents` вместо `.claude`. Профиль личный, в репозиторий его не кладут.

## Чем отличается от superpowers:brainstorming

superpowers:brainstorming выясняет, чего вы хотите, и пишет дизайн до сборки; с релиза [v7.0.0](https://github.com/obra/superpowers/releases/tag/v7.0.0) он и сам перебирает идеи, но про себя. brainstorm-critic разводит варианты открыто несколькими углами, отбирает по критериям, записанным заранее, отдаёт критику и заканчивает рекомендацией. Если стоят оба, называйте нужный явно.

## Сколько стоит

Быстрый режим работает в одном разговоре. Полный режим запускает пять-шесть субагентов (четыре угла, критик, поиск), это заметная часть лимита подписки за раз. Для узких вопросов просите быстрый.

## Пример: модуль «Найм»

Промпт 1.4: «Проведи брейншторм вариантов роли по 01_роль/профиль.md скиллом brainstorm-critic в режиме „без критика“: сначала широко, потом отбери 2–4…». Критик идёт отдельным промптом 1.5, поэтому здесь режим без критика.
