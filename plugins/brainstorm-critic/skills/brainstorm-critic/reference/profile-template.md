# Шаблон профиля для brainstorm-critic

Профиль добавляет к универсальному скиллу то, что знаете только вы: где лежат ваши материалы, какими агентами вы ищете и проверяете, какие углы и критерии вам ближе, какие наблюдения вы уже сделали. Без профиля скилл работает на штатном: ищет в папке, из которой запущен Claude Code, и в её `CLAUDE.md`, поиск отдаёт субагенту `Explore`.

Куда положить (скилл берёт первый найденный):

1. `.agents/brainstorm-critic/profile.md` в корне проекта (только для него, Codex и Claude Code);
2. `~/.agents/brainstorm-critic/profile.md` (для всех проектов);
3. `.claude/brainstorm-critic/profile.md` в корне проекта;
4. `~/.claude/brainstorm-critic/profile.md`.

Профиль личный: в публичный репозиторий и плагины его не кладут. Пустые разделы можно удалить.

```markdown
# Профиль brainstorm-critic: <имя>

## Кто я
Роль и ремесло одной-двумя фразами. От этого зависит угол 1 «своё ремесло».

## Где искать сырьё для шага 0
Полные пути, по порядку:
- <папка заметок или хранилище, например ~/Documents/Notes/>
- <папка прошлых ресёрчей>
- <база о себе или о проекте>
Предупреждения о поиске: <например «нужное часто лежит не в той папке, где кажется: искать по всему хранилищу»>

## Реестры решений
Как называются и где лежат: <например «файл РЕЕСТР_решений.md в папке проекта или раздел 0 рабочего документа»>.
Куда записывать решение штурма: <реестр проекта / файл решений>.

## Свои субагенты
- Поиск по заметкам: <имя агента> (вместо Explore)
- Проверка фактов по первоисточникам: <имя агента>
- Другая модель для критика, если есть: <имя агента или модель>

## Свои углы и рамки
- Угол 1 «своё ремесло» для меня это: <например «консультантская логика, пирамида, сравнимые случаи из практики»>
- Соседние ремёсла, которые мне полезны: <…>
- Критерии схождения по умолчанию: <например «цена в моих часах», «чем проверяется за неделю»>

## Куда класть файлы
Вне проекта: <папка>. В отчёте: <например «полные пути от домашнего каталога»>.

## Порядок работы
- Параллельный запуск субагентов: <«спрашивать, пачкой или частями» / «запускать без вопроса»>
- Кто принимает решение: <я / команда>

## Мои наблюдения и предупреждения
Что вы заметили на своих штурмах и хотите, чтобы скилл помнил. Коротко, по пункту на строку.
```
