# Шаг 0: где искать своё сырьё

Цель шага одна: до первой идеи узнать, что уже решено, что отвалилось и какая фактура лежит под рукой. Идеи без этого получаются средними и повторяют отвергнутое.

## Где искать, по порядку

0. **Места из профиля пользователя**, если профиль есть (пути поиска профиля в SKILL.md). Профиль называет хранилище заметок, папку ресёрчей, реестры решений и предупреждения о поиске. Эти места идут первыми, остальные пункты ниже дополняют их.
1. **Папка текущей работы.** Корень проекта, из которого запущен Claude Code, и её подпапки. Если в корне есть `CLAUDE.md` со схемой папок, сначала прочитать его: там сказано, где лежат входы.
2. **База о себе или о проекте**, если пользователь её завёл. Обычные места: `00_база/`, `база/`, `about-me/`, файл описи (`опись.md`, `inventory.md`). Для задач про карьеру это главный источник: резюме, профиль, истории, отзывы.
3. **Реестр решений**, если он есть: файл с «реестр», «решения», «decisions» в имени или раздел «Решения» в рабочем документе. Нет реестра, значит решения искать в итоговых файлах прошлых шагов.
4. **Прошлые штурмы и разборы по теме**: файлы и папки `Штурм_*`, `brainstorm*`, `критик*`, `варианты*`.
5. **Заметки пользователя вне проекта**, только если путь назван в профиле или в запросе (хранилище заметок, папка с ресёрчами). Без названного пути весь домашний каталог не обходить.

## Как искать

- Есть субагент для поиска по файлам: сначала тот, что назван в профиле, иначе штатный `Explore` в Claude Code. Отдать поиск ему, чтобы найденные файлы не заполняли главный контекст. Нет субагентов: искать самому через Grep и Glob, читать выдержки, а не файлы целиком.
- Искать по имени файла и по содержимому, по нескольким словам темы и их синонимам.
- Не ограничиваться папками, которые «кажутся подходящими»: нужное часто лежит в соседней.

## Что вернуть

Три списка, у каждого пункта путь к файлу:

- **Решено и не пересматривается.** Эти варианты в расхождение не идут.
- **Отвалившиеся ветки** с причиной. Опровергнутая гипотеза это отсечённая ложная ветка; предлагать её заново значит ходить по кругу.
- **Фактура под рукой**: цифры, цитаты, истории, куски прошлых ресёрчей.

## Если шаг 0 ничего не нашёл

Это нормально для первого прохода. Записать «шаг 0: решений и отсечений нет, фактура: <что есть>» и продолжать. Спросить пользователя одним сообщением, только если без ответа штурм пойдёт мимо цели: например, есть ли уже отвергнутые варианты, о которых нет записей.

## Если тот же штурм уже проводился

Найден прошлый штурм по той же теме: не повторять его. Спросить или по запросу понять, что нужно:

- **второй круг**: углы получают список прошлых вариантов как запретный и ищут за его пределами;
- **пересмотр**: прошлые варианты идут на вход режима «развилка» или «критик» с новой фактурой;
- **только проверка**: режим «критик» по прошлому итогу.
