## Как гонять

Результаты держите вне репозитория.

```bash
RUN=~/evals-runs/$(date +%Y%m%d)_<метка>
python3 run.py --run $RUN --all --jobs 2
```

Прогон всех 17 кейсов на Sonnet занимает 10–20 минут. Не больше двух `claude -p` параллельно, ноутбук на зарядке.

Механика (`score.json`) проверяет только то, что проверяется без суждения: ошибки `check.py`, сохранность фактов, запрещённое в выходе, новые числа, близость к исходнику у кейса A04. Голос, уместность правки и интонацию оцените, прочитав `output.md` хотя бы у A04, A08 и A09.

Сравнение версий: разверните старую через `git worktree add /tmp/aaw-old <коммит>` и передайте `--skill-dir /tmp/aaw-old/plugins/anti-ai-writing/skills/anti-ai-writing`. Минимум два прогона на версию: разброс между прогонами одной версии сопоставим с эффектом правки.

Пересчитать оценки после правки критериев: `python3 run.py --run $RUN --score-only --all`.

## Правила набора

- Кейс добавляется из реального провала, в `origin` что случилось.
- `must_keep` и `must_not` это регулярные выражения. Пишите их шире формы слова («распознавани», а не «распознавание»).
